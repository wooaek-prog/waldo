# 처음 쓰는 분을 위한 안내

계열사 뉴스 실시간 모니터를 **내 노트북에서** 켜는 방법입니다.
컴퓨터를 잘 몰라도 따라 할 수 있게 하나씩 적었습니다.

- 걸리는 시간: 처음 한 번만 **10분쯤**, 그 다음부터는 **더블클릭 한 번**
- 돈: **안 듭니다** (네이버 API 무료 범위 안에서 씁니다)
- 이 프로그램은 **내 노트북 안에서만** 돕니다. 인터넷에 공개되지 않고, 다른 사람은 볼 수 없습니다.

---

## 1단계 — 파일 내려받기

1. https://github.com/wooaek-prog/waldo 에 들어갑니다.
2. 브랜치를 `claude/hyundai-elevator-news-realtime-ebcsxp` 로 바꿉니다.
   (페이지 왼쪽 위 `main` 이라고 적힌 버튼을 누르면 목록이 나옵니다.)
3. 초록색 **`< > Code`** 버튼 → **`Download ZIP`** 을 누릅니다.
4. 받은 ZIP 파일의 압축을 풉니다.
   - 윈도우: 파일에 오른쪽 클릭 → `압축 풀기`
   - 맥: 파일을 더블클릭
5. 압축이 풀린 폴더를 **바탕화면**처럼 찾기 쉬운 곳에 둡니다.

폴더 안에 `news` 라는 폴더가 있습니다. 앞으로 쓸 건 전부 그 안에 있습니다.

---

## 2단계 — 파이썬 설치 (이미 있으면 건너뛰기)

이 프로그램은 파이썬이라는 무료 프로그램 위에서 돕니다.

**맥을 쓰신다면** 보통 이미 깔려 있습니다. 3단계로 바로 가세요.
(안 깔려 있으면 3단계에서 알려 줍니다.)

**윈도우를 쓰신다면**

1. https://www.python.org/downloads/ 에 들어갑니다.
2. 노란색 **`Download Python 3.x.x`** 버튼을 누릅니다.
3. 받은 파일을 실행합니다.
4. ⚠️ **첫 화면 맨 아래 `Add python.exe to PATH` 를 꼭 체크하세요.**
   이걸 놓치면 나중에 "파이썬을 찾지 못했습니다" 라고 나옵니다.
5. `Install Now` 를 누르고 끝날 때까지 기다립니다.

---

## 3단계 — 실행하기

`news` 폴더를 열고, 쓰시는 컴퓨터에 맞는 파일을 **더블클릭**합니다.

| 컴퓨터 | 더블클릭할 파일 |
| --- | --- |
| 윈도우 | `start-windows.bat` |
| 맥 | `start-mac.command` |

검은 창(또는 흰 창)이 하나 뜹니다. **이 창은 닫지 마세요.** 이 창이 뉴스를 모으는 중입니다.

> **맥에서 "확인되지 않은 개발자" 경고가 뜨면**
> `start-mac.command` 에 오른쪽 클릭(또는 `Control` 키를 누른 채 클릭) → `열기` →
> 다시 한번 `열기` 를 누르면 됩니다. 처음 한 번만 이렇게 하면 됩니다.

---

## 4단계 — 네이버 API 키 넣기

처음 실행하면 창에 **"네이버 검색 API 키가 아직 없습니다"** 라고 뜨면서 키를 물어봅니다.

키가 있으면 네이버뉴스에 기사가 올라오는 걸 정확히 잡아냅니다.
**지금 당장 받기 번거로우면 그냥 `Enter` 키를 누르세요.** 구글 뉴스로 대신 동작하고,
나중에 언제든 넣을 수 있습니다.

> ⚠️ **가장 헷갈리는 지점 — 사이트를 잘못 찾아가는 경우**
> 네이버에는 이름이 비슷한 서비스가 두 개 있습니다.
>
> | | 필요한 것 ✅ | 아닌 것 ❌ |
> |---|---|---|
> | 이름 | 네이버 **개발자센터** | 네이버 **클라우드 플랫폼** |
> | 주소 | **developers.naver.com** | ncloud.com / console.ncloud.com |
> | 키 모양 | `Ab3dEfGh1JkLmN0pQrSt` (ID, 20자쯤)<br>`AbCdEfGhIj` (Secret, 10자쯤) | `ncp_iam_BPAMKR...`<br>`ncp_iam_BPKMKR...` |
> | 검색 API | 있음 | **없음** |
>
> 키가 **`ncp_iam_` 으로 시작하면 잘못 찾아간 것**입니다. 그 키로는 절대 동작하지 않습니다
> (인증 방식 자체가 다릅니다). 프로그램이 이걸 감지해서 알려 주고 저장하지 않습니다.
> 잘못 만든 NCP 인증키는 콘솔에서 삭제해 두세요.

키 받는 법 (2~3분):

1. https://developers.naver.com/apps/#/register 에 들어가 네이버 계정으로 로그인합니다.
2. **애플리케이션 이름**: 아무거나 적으면 됩니다. (예: `계열사뉴스`)
3. **사용 API**: 목록에서 **`검색`** 을 고릅니다.
4. **환경 추가**: **`WEB 설정`** 을 고르고, 주소 칸에 `http://127.0.0.1:8765` 를 붙여넣습니다.
5. **등록하기** 를 누르면 다음 화면에 **Client ID** 와 **Client Secret** 이 나옵니다.
6. 검은 창으로 돌아와 **Client ID** 를 붙여넣고 `Enter`, **Client Secret** 을 붙여넣고 `Enter`.

> ⚠️ **ID 와 Secret 을 바꿔 넣지 않도록 주의하세요.** 가장 흔한 실수입니다.
> 네이버에서 **Client ID 가 Client Secret 보다 훨씬 깁니다.**
> (바꿔 넣으면 프로그램이 알아채고 다시 입력할 기회를 줍니다.)

> **붙여넣기가 안 될 때**
> 윈도우 검은 창에서는 `Ctrl+V` 대신 **오른쪽 클릭**을 하면 붙여넣기가 됩니다.
> 맥은 `Command+V` 그대로 됩니다.
> 입력한 글자가 화면에 안 보여도 정상인 경우가 있으니, 그냥 붙여넣고 `Enter` 를 누르세요.

한 번 넣으면 이 노트북에 저장되어 **다음부터는 안 물어봅니다.**

## 5단계 — 화면 보기

키를 넣고 잠시 기다리면 창에 이런 줄이 뜹니다.

```
 준비 끝! 브라우저에서 이 주소를 여세요 →  http://127.0.0.1:8765/
```

**브라우저가 저절로 열립니다.** 안 열리면 크롬이나 엣지를 켜고 주소창에
`http://127.0.0.1:8765` 를 직접 입력하세요.

처음에는 화면이 비어 있습니다. **2~3분 정도** 기다리면 기사가 채워집니다.
(계열사를 하나씩 돌아가며 조회하기 때문에 한 바퀴 도는 데 그 정도 걸립니다.)

> 처음 한 바퀴는 **이미 나와 있던 기사를 모으는 구간**이라 알림이 뜨지 않습니다.
> 이 구간이 지나야 "새로 올라온 기사"를 구분할 수 있습니다.
> 그 뒤부터 새 기사가 뜨면 화면 맨 위에 빨갛게 깜빡이며 꽂히고, 오른쪽 아래에 알림이 뜹니다.

---

## 매일 쓰는 방법

1. 아침에 `start-windows.bat` (맥은 `start-mac.command`) 를 **더블클릭**합니다.
2. 브라우저가 열리면 그 탭을 켜 둡니다.
3. 새 기사가 뜨면 알아서 화면에 나타납니다.
4. 끝낼 때는 검은 창을 닫으면 됩니다.

**노트북을 켜 두고 검은 창도 켜 둬야** 뉴스를 계속 모읍니다.
노트북이 잠자기 모드로 들어가면 그동안은 멈추고, 깨어나면 다시 시작합니다.

브라우저 탭을 닫아도 검은 창만 살아 있으면 뉴스는 계속 모입니다.
나중에 다시 `http://127.0.0.1:8765` 를 열면 그동안 모인 기사가 다 보입니다.

## 화면 사용법

| 버튼 | 하는 일 |
| --- | --- |
| 위쪽 **색깔 칩** (전체 / CJ그룹 / HDC그룹 / 현대엘리베이터 계열) | 그룹별로 걸러 봅니다. 빨간 `+숫자` 는 아직 안 읽은 기사 수입니다. |
| 왼쪽 **계열사 목록** | 계열사 하나만 골라 봅니다. 다시 누르면 해제됩니다. |
| **네이버뉴스만** | 네이버에 등록된 기사만 봅니다. |
| **🔔 소리** | 새 기사가 오면 소리로 알려 줍니다. |
| **🖥 알림** | 다른 창을 보고 있어도 알림이 뜹니다. (누르면 브라우저가 권한을 물어보는데 `허용`) |
| **🌓** | 밝은 화면 / 어두운 화면 전환 |
| 검색칸 | 제목과 요약에서 단어를 찾습니다. |

- 기사 카드를 누르면 네이버뉴스로 이동합니다.
- `원문 보기 ↗` 를 누르면 언론사 원문으로 갑니다.
- 안 읽은 기사가 있으면 브라우저 **탭 제목에 `(3)` 처럼 숫자**가 뜨고 아이콘이 빨개집니다.

## 감시할 회사 바꾸기

`news` 폴더의 **`companies.json`** 파일을 메모장(맥은 텍스트 편집기)으로 열어 고치면 됩니다.

예를 들어 `CJ씨푸드` 를 빼고 싶으면 이 줄을 지웁니다.

```json
{ "keyword": "CJ씨푸드", "aliases": ["CJ씨푸드"] },
```

회사를 추가하려면 같은 모양으로 한 줄 넣습니다.

```json
{ "keyword": "현대무벡스", "aliases": ["현대무벡스"] },
```

- `keyword` = 네이버에 실제로 검색할 말
- `aliases` = 제목이나 요약에 이 말이 있어야 통과 (엉뚱한 기사 거르는 용도)

고친 뒤에는 검은 창을 닫고 **다시 더블클릭**해야 반영됩니다.

> ⚠️ 쉼표(`,`)와 중괄호(`{ }`)를 실수로 지우면 프로그램이 안 켜집니다.
> 고치기 전에 파일을 복사해서 백업해 두시면 안전합니다.
> 만약 망가졌다면 GitHub에서 `companies.json` 만 다시 받아 덮어쓰면 됩니다.

**회사를 줄이면 새 기사가 더 빨리 뜹니다.** 32개면 한 바퀴에 2~3분이지만,
10개로 줄이면 1분 안쪽입니다.

## 문제가 생겼을 때

> **뭐가 문제인지 모르겠을 때는 점검 기능을 쓰세요.**
> 실행 파일에 ` --doctor` 를 붙여 돌리면 파이썬 버전, 인증서 상태, 인터넷 연결,
> API 키를 차례로 확인하고 **원인과 해결 방법을 짚어 줍니다.**
> 가장 쉬운 방법은 `news` 폴더에서 검은 창(윈도우는 명령 프롬프트, 맥은 터미널)을 열고
> 아래를 입력하는 것입니다.
>
> ```
> python3 server.py --doctor
> ```
> (윈도우에서 `python3` 가 안 되면 `py -3 server.py --doctor` 로 해보세요.)

**`CERTIFICATE_VERIFY_FAILED` / "인증서를 확인하지 못했습니다" 라고 나와요**

인터넷에서 정보를 안전하게 받아오려면 파이썬이 "믿을 수 있는 기관 목록"을 갖고 있어야 하는데,
그 목록이 비어 있을 때 나는 오류입니다. 프로그램 문제가 아니라 파이썬 설치 문제입니다.

- **맥이라면** (가장 흔한 경우)
  `Finder` → `응용 프로그램` → `Python 3.x` 폴더 → **`Install Certificates.command`** 를 더블클릭하세요.
  검은 창이 잠깐 떴다 사라지면 끝입니다. 그다음 다시 실행하면 됩니다.
- **윈도우라면**
  먼저 이걸 해보세요.
  ```
  pip install --upgrade certifi
  ```
  `Successfully installed certifi-...` 라고 나오면 설치 성공입니다.
  (맨 아래 `[notice] A new release of pip is available` 은 오류가 아니라 그냥 안내이니 무시하세요.)
  설치했으면 **프로그램을 다시 실행**하세요. 이제 자동으로 이 인증서를 찾아 씁니다.

- **certifi 를 깔았는데도 같은 오류가 나요**
  1. **파이썬이 여러 개 깔려 있어** 엉뚱한 곳에 설치됐을 수 있습니다.
     `--doctor` 를 돌리면 `실행파일:` 줄에 실제로 쓰이는 파이썬 경로가 나옵니다.
     그 경로가 `pip` 설치 메시지에 나온 경로와 다르면, 그 경로로 직접 설치하세요.
     ```
     "C:\Users\...\python.exe" -m pip install --upgrade certifi
     ```
     (따옴표까지 그대로 넣으세요. 경로에 공백이 있어도 안전합니다.)
  2. 그래도 안 되면 **회사 보안 프로그램이 통신을 들여다보는 환경**입니다.
     전산팀에서 **인증서 파일(`.crt` 또는 `.pem`)** 을 받아 실행할 때 경로를 지정하세요.
     ```
     python3 server.py --ca-bundle C:\회사인증서.crt
     ```

> 인터넷에 "SSL 검증을 끄면 된다"는 방법이 돌아다니는데, **그렇게 하지 마세요.**
> 통신 내용이 그대로 노출됩니다. 이 프로그램은 검증을 끄는 기능을 일부러 넣지 않았습니다.

**"파이썬을 찾지 못했습니다" 라고 나와요**
2단계를 다시 하세요. 윈도우라면 설치할 때 `Add python.exe to PATH` 체크를 놓쳤을 가능성이 큽니다.
파이썬을 지우고 다시 설치하면서 그 칸을 꼭 체크하세요.

**검은 창이 떴다가 바로 사라져요**
`news` 폴더 안이 아니라 다른 곳에서 파일을 실행했을 수 있습니다.
압축을 푼 폴더 → `news` 폴더 안에 있는 파일을 더블클릭하는지 확인하세요.

**브라우저에 "연결할 수 없음" 이라고 나와요**
검은 창이 아직 켜져 있는지 보세요. 창을 닫았다면 다시 더블클릭하면 됩니다.
주소도 확인하세요 — `https` 가 아니라 **`http`** 입니다.

**`HTTP 401` / "NID AUTH Result Invalid" / "인증에 실패했습니다" 라고 나와요**

네이버가 "이 키는 우리 것이 아니다"라고 답한 상태입니다. 키를 다시 넣으면 됩니다.
`news` 폴더에서 **`set-key-windows.bat`**(맥은 **`set-key-mac.command`**)를 더블클릭하면
키를 새로 물어보고 그대로 실행됩니다.

키를 다시 넣기 전에 아래를 확인하세요. 대부분 이 중 하나입니다.

0. **키가 `ncp_iam_` 으로 시작한다** — 네이버 **클라우드 플랫폼**(ncloud.com) 키입니다.
   필요한 건 네이버 **개발자센터**(developers.naver.com)의 검색 API 키입니다. 위 4단계의
   비교표를 보세요. 이 경우는 다시 넣어도 소용없고, 올바른 사이트에서 새로 받아야 합니다.
1. **Client ID 와 Client Secret 을 바꿔 넣었다** — 가장 흔합니다.
   네이버에서 **ID 가 Secret 보다 훨씬 깁니다**(대략 20자 vs 10자).
   이제 프로그램이 이 실수를 감지해서 다시 입력할 기회를 줍니다.
2. **앞뒤 공백이나 줄바꿈이 같이 복사됐다** — 이제 자동으로 잘라냅니다.
3. **개발자센터에서 `검색` API 를 추가하지 않았다**
   https://developers.naver.com/apps/#/list 에서 내 앱을 열고,
   `API 설정` 탭의 **사용 API** 에 `검색` 이 있는지 확인하세요. 없으면 추가합니다.
4. **다른 앱의 키를 넣었다** — 앱이 여러 개면 어느 앱 것인지 확인하세요.

> 키가 3번 연속 거부되면 프로그램이 **구글 뉴스로 자동 전환**합니다.
> 기사는 계속 모이지만 `네이버뉴스` 배지는 안 붙습니다. 화면 위쪽에 노란 띠로 알려 줍니다.
> 잘못된 키로 계속 두드리지 않게 하려는 장치입니다.

**키를 다시 넣고 싶어요**
`set-key-windows.bat`(맥은 `set-key-mac.command`)를 더블클릭하세요.
또는 `news` 폴더에서 `.naver_key.json` 파일을 지우고 다시 실행해도 됩니다.

**기사가 하나도 안 떠요**
- 아직 2~3분이 안 지났을 수 있습니다. 조금 더 기다려 보세요.
- 화면 위쪽에 **노란 띠**가 떠 있으면 거기 원인과 해결 방법이 적혀 있습니다.
- `네이버뉴스만` 버튼이 켜져 있으면 꺼 보세요.
- 그래도 모르겠으면 위에 적힌 `--doctor` 점검을 돌려 보세요.

**"오늘 API 호출 한도를 다 썼습니다"**
네이버 무료 한도는 하루 25,000번입니다. 다음 날 자동으로 풀립니다.
자주 그러면 `companies.json` 에서 회사 수를 줄이세요.

## 알아 두시면 좋은 것

- **인터넷에 공개되지 않습니다.** 주소가 `127.0.0.1` 인데, 이건 "내 컴퓨터"라는 뜻입니다.
  같은 와이파이의 다른 사람도 볼 수 없습니다.
- **API 키는 이 노트북에만** `news/.naver_key.json` 파일로 저장됩니다. 어디로도 전송되지 않습니다.
- 모아 둔 기사 목록은 `news/.state.json` 에 저장됩니다. 껐다 켜도 예전 기사가
  새 기사로 다시 뜨지 않는 건 이 파일 덕분입니다.
- 네이버 검색 API는 **제목과 짧은 요약만** 줍니다. 본문은 기사를 눌러서 보셔야 합니다.

더 자세한 설정과 기술적인 내용은 [`README.md`](README.md) 에 있습니다.
