# 계열사 뉴스 실시간 모니터

CJ그룹 · HDC그룹 · 현대엘리베이터 계열(현대그룹)의 계열사 뉴스가 **네이버뉴스에 등록되는 즉시**
브라우저 화면에 밀어 넣어 주는 실시간 대시보드입니다.

> **처음 쓰시나요?** 명령어 없이 더블클릭으로 시작하는 방법은
> **[START-HERE.md](START-HERE.md)** 에 단계별로 적어 뒀습니다.
> 아래 내용은 설정과 동작 원리를 다룹니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체. 빌드 도구 없이 이 파일 하나로 동작합니다. |
| `server.py` | 네이버 검색 API를 계속 폴링하고 SSE로 브라우저에 푸시하는 서버. 표준 라이브러리만 사용합니다. |
| `companies.json` | 감시할 계열사 목록. 화면에서 고칠 수 있고, 직접 편집해도 됩니다. |
| `exchange.py` | 환율 수집. 수출입은행 매매기준율을 우선 쓰고, 안 되면 다른 소스로 내려갑니다. |
| `start-windows.bat` / `start-mac.command` | 더블클릭 실행용. 파이썬을 찾아 서버를 켜고 브라우저를 엽니다. |
| `set-key-windows.bat` / `set-key-mac.command` | 더블클릭하면 네이버 API 키를 새로 입력받고 그대로 실행합니다. |
| `set-exim-key-windows.bat` / `set-exim-key-mac.command` | 더블클릭하면 수출입은행 환율 API 키를 새로 입력받습니다. |

## 왜 서버가 필요한가

브라우저 자바스크립트가 네이버 API를 직접 부를 수는 없습니다.

- 네이버가 **CORS** 를 허용하지 않아 브라우저에서 보낸 요청은 차단됩니다.
- API 키(Client Secret)를 HTML 안에 넣으면 페이지를 여는 누구에게나 노출됩니다.

그래서 키를 들고 있는 얇은 로컬 서버를 함께 둡니다. 이 서버는 계열사를 한 곳씩 돌아가며 조회하고,
새 기사만 골라 **SSE(Server-Sent Events)** 로 밀어 줍니다. 브라우저가 주기적으로 새로고침하지
않아도 되고, 탭을 여러 개 열어도 API 호출량은 그대로입니다.

## 실행

```bash
python3 news/server.py
```

이게 전부입니다. 설치할 것도, 미리 설정할 것도 없습니다. 서버가 뜨면 브라우저가 자동으로
열립니다(`--no-open` 으로 끌 수 있습니다).

**API 키**는 처음 실행할 때 화면에서 물어보고, 한 번 넣으면 `news/.naver_key.json` 에
저장되어 다시 묻지 않습니다. 키를 찾는 순서는 다음과 같습니다.

1. `--client-id` / `--client-secret` 인자
2. `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` 환경변수
3. 저장해 둔 `news/.naver_key.json`
4. 위가 모두 없으면 화면에서 직접 입력 (`--set-key` 로 언제든 새로 입력)

### 어느 창구의 키인가

2026년 네이버가 검색 API 를 개발자센터에서 **NAVER API HUB**(네이버 클라우드)로 이관했습니다.

| | NAVER API HUB | 개발자센터(구) |
| --- | --- | --- |
| 주소 | `naverapihub.apigw.ntruss.com/search/v1/news` | `openapi.naver.com/v1/search/news.json` |
| 헤더 | `X-NCP-APIGW-API-KEY-ID` / `X-NCP-APIGW-API-KEY` | `X-Naver-Client-Id` / `X-Naver-Client-Secret` |
| 발급 | 콘솔 → NAVER API HUB → Application → API 관리 → `[인증 정보]` | 신규 발급 불가 |
| 기한 | 계속 | 이관 신청한 기존 사용자만 2027-06-30 까지 |

응답 형식(`title`/`originallink`/`link`/`description`/`pubDate`)은 같아서 파싱 코드는 하나로
공유합니다. 두 창구는 키 생김새로 구분할 수 없으므로, 시작할 때 **양쪽에 한 번씩 시험
조회를 보내 통과하는 쪽을 고릅니다**(`--api auto`, 기본값). `--api hub` / `--api legacy` 로
직접 지정할 수도 있습니다. 네트워크 문제로 판별에 실패하면 신규 발급처인 API HUB 를 씁니다.

> ⚠️ 콘솔의 `계정관리 → 인증키 관리` 에 있는 `ncp_iam_` Access Key 는 클라우드 전체용이라
> 검색 API 인증에 쓰이지 않습니다. API HUB 의 `[인증 정보]` 값을 써야 합니다.

입력한 키는 앞뒤 공백·따옴표를 정리해 저장하고, 공백이 섞였거나 `ncp_iam_` Access Key 로
보이면 알려 줍니다(막지는 않습니다 — 최종 판정은 위의 실제 호출로 합니다).

키 없이도 실행됩니다. 이때는 **구글 뉴스 RSS 폴백**으로 동작하는데, 기사 수집은 되지만
네이버뉴스 등록 여부는 알 수 없어 `네이버뉴스` 배지가 붙지 않습니다.

**키가 거부되면**(HTTP 401/403) 3회 연속 실패한 시점에 구글 뉴스로 자동 전환합니다.
잘못된 키로 하루치 호출 한도를 태우지 않기 위해서입니다. 전환 사실은 서버 로그와
웹 화면 배너에 남고, `set-key-*` 로 키를 고치면 됩니다.

> `index.html` 을 파일 탐색기에서 더블클릭해 열면 데이터를 가져올 수 없습니다.
> 그 경우 화면에 위 실행 방법을 안내하는 배너가 뜹니다.

### 실행 옵션

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--port` | `8765` | 접속 포트 |
| `--host` | `127.0.0.1` | `0.0.0.0` 으로 바꾸면 같은 네트워크의 다른 기기에서도 접속할 수 있습니다. |
| `--display` | `30` | 계열사당 한 번에 가져올 기사 수 (10~100) |
| `--daily-budget` | `20000` | 하루 API 호출 상한. 이 값으로 요청 간격을 자동 계산합니다. |
| `--min-cycle` | `90` | 전체 계열사를 한 바퀴 도는 최소 시간(초) |
| `--max-age-hours` | `48` | 이보다 오래된 기사는 무시 |
| `--naver-only` | 꺼짐 | 네이버뉴스에 등록된 기사만 수집 |
| `--reset` | 꺼짐 | 저장해 둔 상태를 지우고 처음부터 시작 |
| `--set-key` | 꺼짐 | 저장된 API 키를 지우고 새로 입력받기 |
| `--no-open` | 꺼짐 | 시작할 때 브라우저를 자동으로 열지 않음 |
| `--ca-bundle` | 없음 | HTTPS 검증에 쓸 인증서 파일(.pem/.crt). 사내 프록시 환경용 |
| `--no-rates` | 꺼짐 | 환율 표시를 끕니다 |
| `--rate-interval` | `600` | 환율 갱신 주기(초, 최소 20). 기본 10분 |
| `--exim-key` | 없음 | 한국수출입은행 환율 API 인증키. 한 번 넣으면 저장됩니다 |
| `--set-exim-key` | 꺼짐 | 저장된 환율 API 키를 지우고 새로 입력받기 |
| `--api` | `auto` | 검색 API 창구: `auto`(자동 판별) / `hub` / `legacy` |
| `--doctor` | — | 인증서·연결·API 키를 점검하고 원인을 알려 준 뒤 종료 |

**호출량 계산**: 개발자센터 기준 무료 한도가 하루 25,000회였습니다. API HUB 는 현재 한시적
무료이며 향후 유료 요금제 도입 시 별도 공지 예정이므로, 한도가 바뀌면 `--daily-budget` 을
조정하세요. 기본 설정(감시 대상 32개,
`--daily-budget 20000`)이면 요청 간격이 약 4.3초, 한 바퀴가 약 140초입니다. 즉 새 기사는
**늦어도 2~3분 안에** 화면에 뜹니다. 더 빠르게 하려면 `companies.json` 에서 계열사 수를 줄이세요.

## HTTPS 인증서

`CERTIFICATE_VERIFY_FAILED` 가 나면 파이썬의 루트 인증서 저장소가 비어 있거나(맥의 python.org
설치본에서 흔합니다) 사내 프록시가 TLS를 가로채는 경우입니다.

인증서 처리는 두 단계입니다.

1. 시작할 때 시스템 저장소가 비어 있으면(맥 python.org 설치본에서 흔함) `certifi` 번들로 대체합니다.
2. 저장소가 차 있어도 **실제 검증에 실패하면 `certifi` 로 한 번 더 시도**하고, 성공하면 이후
   요청은 계속 `certifi` 를 씁니다. 윈도우는 저장소가 비어 있지 않은데도 발급기관을 못 찾는
   경우가 있어(루트 인증서 자동 업데이트 차단 등) 1단계만으로는 부족합니다.

certifi 로도 실패하면 사내 프록시가 TLS를 가로채는 환경이므로 `--ca-bundle` 로 사내 CA를
지정하세요. **검증을 끄는 옵션은 제공하지 않습니다.**

원인을 모르겠으면 `--doctor` 가 인증서 개수, 실제 HTTPS 호출 결과, API 키 유무를 한 번에
점검하고 운영체제에 맞는 해결 방법을 알려 줍니다.

```bash
python3 news/server.py --doctor
```

수집 중 인증서 오류가 나면 서버 로그뿐 아니라 **웹 화면 상단 배너에도** 원인과 해결 방법이
표시되고, 문제가 해소되면 배너는 자동으로 사라집니다.

## 환율

상단 띠에 환율을 표시합니다. `통화 선택` 버튼으로 볼 통화쌍을 고르면 브라우저에 기억됩니다.
지원 통화쌍은 달러/원, 엔/원(100엔), 유로/원, 위안/원, 파운드/원, 호주달러/원, 달러/엔, 유로/달러입니다.
USD 기준 환율표에서 교차 계산하므로 통화쌍을 늘리기 쉽습니다(`exchange.py` 의 `PAIRS`).

소스는 순서대로 시도합니다.

| 순서 | 소스 | 갱신 | 전일 대비 | 필요 |
| --- | --- | --- | --- | --- |
| 1 | **한국수출입은행 매매기준율** | 영업일 11시경 1회 | 전영업일과 비교해 계산 | 인증키 |
| 2 | 네이버 금융 시장지표 | 실시간에 가까움 | 제공 | — |
| 3 | Frankfurter(유럽중앙은행) | 평일 하루 1회 | 전영업일과 비교해 계산 | — |
| 4 | ExchangeRate-API | 하루 1회 | 없음 | — |

### 한국수출입은행 매매기준율

인증키를 넣으면 은행이 고시하는 **매매기준율(`deal_bas_r`)** 을 그대로 씁니다. 기준이
분명해서 사내 보고에 쓰기 좋습니다. 키는 https://www.koreaexim.go.kr/ir/HPHKIR020M01?apino=2&viewtype=C
에서 받습니다.

```bash
python3 news/server.py --exim-key 발급받은_인증키   # 한 번만. 그다음부터는 저장된 키를 씁니다
```

키는 `news/.exim_key.json` 에 소유자 전용 권한(0600)으로 저장되며 `.gitignore` 에 들어 있습니다.
`EXIM_API_KEY` 환경변수로 줘도 되고, `--set-exim-key`(또는 `set-exim-key-*` 더블클릭)로 다시 넣을 수 있습니다.

동작상 신경 쓴 부분:

- **주말·공휴일·11시 이전**에는 빈 응답이 오므로, 값이 나올 때까지 하루씩 거슬러 올라가
  가장 최근 고시분을 찾습니다(최대 10일).
- 이미 받은 고시일자와 **지난 날짜의 휴일 여부는 캐시**합니다. 오늘치 빈 응답은 11시 고시를
  기다려야 하므로 캐시하지 않습니다. 그래서 10분 주기로 돌려도 **하루 약 144회**만 호출합니다
  (수출입은행 일일 한도 1,000회).
- 2026-04-30 부터 주소가 `oapi.koreaexim.go.kr` 로 바뀌었습니다. 구 주소도 남겨 두고 통하는
  쪽으로 고정합니다.
- 수출입은행은 **원화 대비 환율만** 줍니다. 달러/엔, 유로/달러는 원화 기준값에서 교차 계산한
  값이라 국제시장 호가와는 조금 다를 수 있습니다.
- 인증키 오류·한도 초과는 사람이 읽을 수 있는 문구로 바꿔 화면에 띄우고, 그래도 안 되면
  다음 소스(네이버 금융 등)로 조용히 내려갑니다.
- 응답 필드는 공식 문서상 대문자(`RESULT` / `CUR_UNIT` / `DEAL_BAS_R`)인데 소문자로 오는
  사례도 있어, **키를 소문자로 정규화해 양쪽 다 읽습니다.**
- 인증키는 URL 인코딩해서 붙입니다(`+`, `/`, `=` 가 들어가도 깨지지 않도록).
- `--doctor` 가 인증키 유무와 실제 조회 결과(달러/원 값, 고시일자)를 보여 줍니다.

> ⚠️ **"10분마다 갱신"의 의미.** 수출입은행 고시는 **영업일 오전 11시경 하루 한 번**입니다.
> 10분마다 조회해도 고시 전까지는 같은 값이 돌아옵니다. 그래서 화면에는 확인 시각과 함께
> **고시일자**(예: `2026-09-11 고시`)를 표시합니다. 10분 주기는 *고시가 올라오면 늦어도
> 10분 안에 반영된다*는 뜻입니다.
> 초 단위로 움직이는 시세가 필요하면 증권사나 유료 데이터 제공사의 API 를 붙여야 합니다.

## 감시 대상 바꾸기

화면 오른쪽 위 **`✏️ 계열사`** 버튼을 누르면 그룹별로 검색어·별칭·제외어를 고치고
추가·삭제할 수 있습니다. 저장하면 `companies.json` 에 쓰이고 **서버를 다시 켜지 않아도**
바로 반영됩니다. 직전 파일은 `companies.json.bak` 으로 남습니다.

저장 전에 검증을 거치므로(빈 검색어, 그룹 id 중복, 계열사 0개, 300개 초과 등) 잘못된 설정이
파일에 들어가 다음 실행이 실패하는 일은 없습니다.

새로 추가한 계열사는 **첫 한 바퀴를 조용히 수집**합니다. 그러지 않으면 그 회사의 기존 기사가
전부 "새 기사" 알림으로 쏟아집니다.

파일을 직접 고쳐도 됩니다. 그때는 서버를 다시 실행하세요.

```json
{ "keyword": "현대무벡스", "aliases": ["현대무벡스"], "exclude": ["무관한말"] }
```

- `keyword` — 네이버에 실제로 던지는 검색어
- `aliases` — 제목이나 요약에 이 중 하나라도 있어야 통과 (검색 노이즈 제거용)
- `exclude` — 이 표현이 있으면 버림

비교할 때 공백·괄호·가운뎃점은 무시하므로 `CJ ENM` 과 `CJENM` 은 같게 취급됩니다.

기본 목록은 공개된 계열사 정보를 바탕으로 채워 넣은 것이라, 지분 변동이나 사명 변경이 있으면
직접 손봐 주세요.

## 화면 기능

- **실시간 푸시** — 새 기사가 뜨면 카드가 맨 위에 깜빡이며 꽂히고 토스트가 뜹니다.
- **네이버 등록 감지** — 원문만 있던 기사가 나중에 네이버뉴스에 올라오면 그 순간을 따로 알립니다.
- **네이버뉴스만** — 네이버에 등록된 기사만 걸러 봅니다.
- **그룹 / 계열사 필터** — 상단 칩으로 그룹을, 왼쪽 목록으로 개별 계열사를 고릅니다. 숫자는 읽지 않은 건수입니다.
- **소리 · 데스크톱 알림** — 각각 버튼으로 켭니다(알림은 브라우저 권한 필요).
- **읽지 않음 표시** — 탭 제목과 파비콘 색으로 알려 줍니다.
- **환율 띠** — 상단에 계속 표시하고, 볼 통화쌍을 직접 고릅니다.
- **계열사 편집** — 화면에서 추가·수정·삭제하고 즉시 반영합니다.
- 다크 모드와 모바일 화면 폭을 지원하고, 설정은 브라우저에 기억됩니다.

한 기사에 여러 계열사가 나오면(예: `CJ제일제당·CJ대한통운 공동 협약`) 카드 하나에 두 계열사가
모두 태그로 붙고, 양쪽 필터에서 전부 보입니다.

## API

| 엔드포인트 | 설명 |
| --- | --- |
| `GET /api/stream` | SSE. `snapshot` / `news` / `update` / `status` 이벤트 |
| `GET /api/news?since=<epoch>&limit=` | 기사 목록(JSON). SSE를 못 쓰는 환경용 |
| `GET /api/config` | 그룹·계열사 목록과 서버 상태 |
| `GET /api/status` | 서버 상태만 |
| `GET /api/refresh` | 다음 조회를 즉시 실행 |
| `GET /api/companies` | 계열사 설정(companies.json) 조회 |
| `PUT /api/companies` | 계열사 설정 저장. 검증 후 `.json.bak` 백업, 재시작 없이 반영 |
| `GET /api/rates` | 최신 환율 스냅샷 |

## 알아 둘 점

- 처음 실행하면 **첫 한 바퀴는 기존 기사를 모으는 구간**이라 알림이 뜨지 않습니다. 이 구간이 끝나야
  "새 기사"를 구분할 수 있습니다.
- 수집 상태는 `news/.state.json` 에 저장되므로 서버를 껐다 켜도 예전 기사가 새 기사로 다시 뜨지 않습니다.
- 네이버 검색 API는 기사 전문이 아니라 제목·요약만 돌려줍니다. 본문은 카드를 눌러 원문에서 확인하세요.
- 서버는 기본적으로 `127.0.0.1` 에만 바인딩하므로 같은 네트워크의 다른 기기에서도 보이지 않습니다.
  API 키는 `news/.naver_key.json` 과 `news/.exim_key.json` 에 소유자 전용 권한(0600)으로 저장되며,
  모두 `.gitignore` 에 들어 있어 커밋되지 않습니다. **키를 코드에 적어 넣지 마세요.**
- 이 도구는 공개된 검색 API 결과를 모아 보여 줄 뿐이며, 기사 저작권은 각 언론사에 있습니다.
