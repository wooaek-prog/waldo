# 학교별·교사동별·운동장별 일조시간 분석 — "동시 재건축이 좋아진다"는 해석의 정정

앞선 [학교 일조영향 보고서](daegyo_school_sunlight.md)에서 화랑 재건축이
학교 일조를 **개선(+2.5%p)** 한다고 보고했으나, 이는 **충족률(%)이라는
문턱 지표가 만든 착시**였습니다. 실제 **일조시간(시간)** 으로 다시 계산한
결과를 보고드립니다.

```bash
python3 daegyo_school_hours.py --buildings <AL_D010.gpkg> --plan <대교신축.gpkg>
```

## 2. 왜 충족률은 올라갔는데 시간은 줄었나 — 문턱 지표의 함정

화랑 재건축(S2)만 놓고 교사동 창면 680개를 하나씩 추적했습니다.

| 항목 | 개수 |
| --- | ---: |
| 일조시간이 **늘어난** 수광점 | 66개 |
| 일조시간이 **줄어든** 수광점 | **371개** |
| 변화 없음 | 243개 |
| 판정 불충족 → 충족 | **18개** |
| 판정 충족 → 불충족 | 1개 |
| **순증 17개 = +2.5%p** | |

**핵심**: 시간이 줄어든 371개 중 **370개는 여전히 "충족" 판정**을 유지했습니다.
이들은 **평균 0.6시간씩 일조를 잃었지만 충족률 통계에는 전혀 잡히지 않습니다.**

기준A는 "연속 2시간 **또는** 총 4시간"이라는 **합격/불합격 문턱**이라,

- 5.5시간 → 4.6시간으로 **0.9시간을 잃어도** 여전히 "충족" → 통계상 변화 0
- 3.9시간 → 4.1시간으로 **0.2시간만 늘어도** "불충족→충족" → 통계상 +1건

즉 **370명의 손실은 세지 않고 18명의 이득만 센 것**이 +2.5%p의 정체입니다.
여의도여고는 현황 평균이 4.32시간으로 문턱에 바짝 붙어 있어(총 3~4시간 구간에
12.6%가 몰려 있음) 작은 증가가 곧바로 충족률로 전환된 반면, 여의도고(평균
5.19h)·여의도중(4.89h)은 여유가 있어 **시간을 잃어도 % 지표가 반응하지
않았습니다.**

> **판단**: 일조 영향의 실질을 보려면 충족률(%)이 아니라 **일조시간(h)** 을
> 함께 봐야 합니다. 이전 보고서의 "화랑 재건축은 개선" 서술은 이 문턱 효과를
> 걸러내지 못한 것으로, 본 문서로 정정합니다.

## 6. 화랑 재건축이 여의도여고에만 도움이 되는 이유

화랑 기존 3개동과 신축 1개동의 **방위**를 여의도여고 기준으로 비교하면:

| 화랑 건물 | 규모 | 여고까지 거리 | 여고 기준 방위 | 그림자 적중 시각 |
| --- | --- | ---: | ---: | --- |
| 기존 1동 | 13.6×57.8m, 30m(10층) | 13.7m | 300.4° | **08:00** |
| 기존 2동 | 13.5×63.4m, 30m(10층) | 22.4m | 328.3° | **10:20** |
| 기존 3동 | 13.5×63.4m, 30m(10층) | 63.3m | 353.2° | **12:10** |
| **신축 1개동** | 21.5×37.0m, **166m(55층)** | 34.9m | 319.1° | **09:40** |

**기존 3개동은 방위 300°/328°/353°에 늘어서서 08:00 → 10:20 → 12:10까지
차례로 그림자를 넘겨주는 "릴레이 차폐"를 만듭니다.** 오전 내내 여고를 가리는
구조입니다. 신축은 1개동뿐이라 09:40 한 번만 지나갑니다.

실제 시간대별 차폐 분해(여의도여고 수광점 542개 중 화랑에 가려진 비율):

| 시각 | S0 현황 | S3 동시 재건축 |
| --- | ---: | ---: |
| 08:00 | **52%** | 27% |
| 09:00 | 32% | 24% |
| 10:00 | 9% | 20% |
| 12:00 | 20% | 11% |
| 15:00 | 23% | 10% |

아침 차폐가 52% → 27%로 풀리는 대신 10시대에 9% → 20%로 늘어납니다.
순효과는 여고에 유리하지만 **"개선"이라기보다 차폐 시간대의 이동**입니다.

### 같은 학교 안에서도 동별로 정반대

| 여의도여고 | 기존동 최단거리 | 신축 최단거리 | S2 변화 |
| --- | ---: | ---: | ---: |
| ②동(최남단) | **13.7m** | 34.9m | **+1.21h** |
| ①동(최북단) | 75.4m | 94.2m | −0.74h |
| ③동 | 74.8m | 99.1m | +0.21h |

- **②동**은 기존 슬래브 바로 옆(13.7m)에 붙어 있어 30m 높이만으로도 오전 내내
  가려졌는데, 신축이 34.9m로 물러나면서 **+1.21시간** 회복합니다.
- **①동**은 75m 떨어져 있어 기존 30m 동의 그림자(09:40 기준 도달거리 116m)
  끝자락에 걸쳐 있었지만, **신축 166m 동의 그림자는 662m까지 뻗어** 멀리 있는
  ①동까지 확실히 덮습니다. 그래서 **−0.74시간** 손해입니다.

> **요약**: 낮고 가까운 3개동 → 바로 옆 ②동을 집중 차폐 /
> 높고 먼 1개동 → 멀리 있는 ①·③동까지 차폐.
> **총량이 줄어든 게 아니라 피해가 재분배된 것**입니다.

```bash
    --apron 45 --focus 40-1
```
