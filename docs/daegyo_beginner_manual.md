# 대교아파트 폴리곤 – 처음 쓰는 분을 위한 상세 매뉴얼

파이썬도 QGIS도 처음이라는 가정에서, **메뉴 클릭 단위로** 설명합니다.
순서대로만 따라 하면 됩니다.

> **먼저 알아둘 것**
> 이 작업의 목표는 "대교아파트 신축 건물 4개 동을 지도 위 정확한 자리에 세우고,
> 겨울철 태양 위치를 넣어 그림자가 어디까지 지는지 보는 것"입니다.
> 건물 모양(폴리곤)과 높이는 이미 만들어 두었으니, 여러분은
> **① QGIS에 불러오고 ② 위치를 맞추고 ③ 그림자를 켜면** 됩니다.

## 1단계. 파일 내려받기

**파이썬을 설치하지 않아도 됩니다.** 결과 파일은 이미 만들어져 저장소에 들어 있습니다.

1. 웹브라우저에서 저장소를 엽니다
   → `https://github.com/wooaek-prog/waldo`
2. 화면 왼쪽 위 **브랜치 선택 버튼**(기본값 `main`)을 클릭 →
   목록에서 **`claude/daekyoapt-sunlight-polygon-x6l6a4`** 선택
3. 초록색 **`< > Code`** 버튼 → **`Download ZIP`** 클릭
4. 내려받은 ZIP을 **압축 해제**합니다.
   경로에 한글·공백이 없는 곳이 좋습니다. 예: `C:\daegyo`

압축을 풀면 아래 파일이 있습니다. **`outputs\daegyo` 폴더**만 있으면 QGIS 작업은 됩니다.

```
C:\daegyo\
├─ daegyo_site_polygons.py          ← 폴리곤 생성 프로그램 (8단계에서 사용)
├─ data\daegyo_site_plan.json       ← 건물 모양·층수 정의 (수정하면 재생성됨)
├─ docs\                            ← 설명 문서
└─ outputs\daegyo\                  ← ★ QGIS에 넣을 결과물
   ├─ daegyo_buildings_epsg5186.geojson       ← ★ 신축 건물 (주 레이어)
   ├─ daegyo_buildings_wgs84.geojson          ← 같은 내용, 위경도 버전
   ├─ daegyo_context_buildings_epsg5186.geojson ← 주변 기존 건물
   ├─ daegyo_site_boundary_epsg5186.geojson   ← 대지경계선
   ├─ daegyo_buildings.csv                    ← 엑셀로 열어보는 용도
   ├─ daegyo_trace_preview.svg                ← 배치도와 겹쳐보는 검수용 그림
   └─ daegyo_polygon_report.md                ← 건물별 높이표·검증 결과
└─ outputs\daegyo_cp_exact\                  ← 기준점 2점에 오차 0m로 맞춘 대안 버전
                                              (대지면적이 인가 제원보다 6.8% 큼)
```

> **`epsg5186`과 `wgs84` 중 뭘 써야 하나요?**
> **`epsg5186`을 쓰십시오.** 단위가 미터라서 거리·면적·그림자 계산이 정확합니다.
> `wgs84`(위도·경도)는 단위가 "도(°)"라 그림자 분석에 부적합하고, 배경지도와
> 겹쳐 눈으로만 확인할 때 씁니다.

## 2단계. QGIS 설치

1. 브라우저에서 **`https://qgis.org`** 접속
2. 상단 메뉴 **`Download`** 클릭
3. 본인 운영체제 선택 후, **`Long Term Version (most stable)`** 을 받으십시오
   - Windows: `QGIS Standalone Installer Version 3.xx (64bit)`
   - Mac: `QGIS macOS Installer Version 3.xx`
   - **3D 그림자 기능은 QGIS 3.16 이상**에서 됩니다. LTR을 받으면 문제 없습니다.
4. 내려받은 설치 파일 실행 → 계속 `Next` → 설치 완료
   - Windows에서 "이 앱이 디바이스를 변경하도록 허용하시겠습니까?" → **예**
5. 시작 메뉴에서 **`QGIS Desktop 3.xx`** 실행
   (`QGIS Desktop with GRASS`가 아니라 그냥 `QGIS Desktop`을 실행하면 됩니다)

> 처음 실행하면 30초~1분 정도 걸릴 수 있습니다. 정상입니다.

## 3단계. QGIS 화면 익히기

처음 열면 복잡해 보이지만, 실제로 쓸 곳은 4군데뿐입니다.

```
┌────────────────────────────────────────────────────────────┐
│ ① 메뉴 막대 : Project  Edit  View  Layer  Settings  ...    │
├──────────────┬─────────────────────────────────────────────┤
│ ② Browser    │                                             │
│   (탐색기)    │                                             │
│              │            ④ 지도 캔버스                      │
├──────────────┤            (지도가 그려지는 곳)                 │
│ ③ Layers     │                                             │
│   (레이어 목록)│                                             │
├──────────────┴─────────────────────────────────────────────┤
│ ⑤ 상태 표시줄 :  Coordinate  ...  Scale  ...  EPSG:xxxx    │
└────────────────────────────────────────────────────────────┘
```

| 번호 | 이름 | 하는 일 |
| --- | --- | --- |
| ① | **메뉴 막대** | 모든 기능의 출발점 |
| ② | **Browser 패널** | 배경지도(XYZ Tiles) 추가하는 곳 |
| ③ | **Layers 패널** | 불러온 레이어 목록. 체크 해제하면 숨겨짐 |
| ④ | **지도 캔버스** | 마우스 휠로 확대/축소, 드래그로 이동 |
| ⑤ | **상태 표시줄** | **마우스 위치 좌표**가 실시간 표시됨 (8단계 핵심) |

**② Browser나 ③ Layers 패널이 안 보이면**
메뉴 **`View → Panels`** 에서 `Browser`, `Layers` 를 체크하십시오.

## 4단계. 좌표계 설정 (가장 중요)

**이 단계를 건너뛰면 건물이 엉뚱한 곳에 그려지거나 좌표를 잘못 읽게 됩니다.**

1. 메뉴 **`Project`** → **`Properties…`** 클릭 (단축키 `Ctrl+Shift+P`)
2. 왼쪽 목록에서 **`CRS`** 탭 선택
3. 가운데 **`Filter`** 검색창에 **`5186`** 입력
4. 아래 목록에 나타나는 **`Korea 2000 / Central Belt 2010  EPSG:5186`** 을 클릭
5. 오른쪽 아래 **`OK`**

제대로 됐는지 확인: 화면 **오른쪽 아래 상태표시줄에 `EPSG:5186`** 이라고 떠야 합니다.

> **왜 5186인가요?**
> 우리나라 중부지역(서울 포함) 표준 좌표계입니다. 단위가 **미터**여서
> "이 건물 그림자가 몇 m 갔는가"를 바로 잴 수 있습니다.
> 위도·경도(EPSG:4326)는 단위가 도(°)라 거리 계산이 어긋납니다.

## 5단계. 배경지도 깔기

건물이 실제로 맞는 자리에 있는지 확인하려면 배경지도가 필요합니다.

### 5-1. 가장 간단한 방법 — OpenStreetMap (설정 불필요)

1. 왼쪽 **`Browser` 패널**에서 **`XYZ Tiles`** 항목을 찾아 **▶ 삼각형**을 눌러 폅니다
2. 그 안의 **`OpenStreetMap`** 을 **더블클릭**
3. 지도 캔버스에 세계지도가 나타납니다

### 5-2. 항공사진 보기 — VWorld (권장, 위치 확인에 훨씬 정확)

1. **`Browser` 패널**의 **`XYZ Tiles`** 위에서 **마우스 오른쪽 클릭**
2. **`New Connection…`** 클릭
3. 아래처럼 입력하고 `OK`

   | 항목 | 입력값 |
   | --- | --- |
   | Name | `VWorld 항공영상` |
   | URL | `https://xdworld.vworld.kr/2d/Satellite/service/{z}/{x}/{y}.jpeg` |
   | Max. Zoom Level | `19` |

4. `XYZ Tiles` 아래 생긴 **`VWorld 항공영상`** 을 더블클릭

> 타일이 안 나오면 서비스가 일시적으로 막힌 것입니다. OpenStreetMap으로 진행하거나,
> 메뉴 `Plugins → Manage and Install Plugins…` 에서 **`QuickMapServices`** 플러그인을
> 설치하면 `Web → QuickMapServices` 메뉴로 여러 위성영상을 쓸 수 있습니다.

### 5-3. 대상지로 이동하기

1. 지도 캔버스 아무 곳이나 클릭한 뒤
2. 화면 아래 **`Coordinate`** 칸에 **`194150,546960`** 을 입력하고 `Enter`
3. **`Scale`** 칸을 **`1:3000`** 정도로 맞춥니다
4. 여의도 동쪽 아파트 지구가 보이면 성공입니다
   (북쪽에 여의도여자고등학교, 서쪽에 삼부아파트)

## 6단계. 건물 폴리곤 불러오기

1. 메뉴 **`Layer`** → **`Add Layer`** → **`Add Vector Layer…`** (단축키 `Ctrl+Shift+V`)
2. 대화상자에서
   - `Source Type` : **`File`** (기본값)
   - `Vector Dataset(s)` 오른쪽 **`…`** 버튼 클릭
3. `C:\daegyo\outputs\daegyo` 폴더로 이동 →
   **`daegyo_buildings_epsg5186.geojson`** 선택 → `열기`
4. 대화상자 아래 **`Add`** 클릭 → 이어서 **`Close`**

같은 방법으로 아래 두 개도 추가하십시오.

- `daegyo_site_boundary_epsg5186.geojson` (대지경계선)
- `daegyo_context_buildings_epsg5186.geojson` (주변 기존 건물)

### 6-1. 잘 들어왔는지 확인

- **`Layers` 패널**에서 레이어 이름 위에 **오른쪽 클릭 → `Zoom to Layer`**
  → 건물 폴리곤이 화면 가득 나타납니다
- **오른쪽 클릭 → `Open Attribute Table`**
  → 17개 행(건물)과 `floors`, `height_m`, `top_elev_m` 같은 열이 보이면 정상입니다

### 6-2. 레이어 순서 정리

`Layers` 패널에서 **드래그**해서 위아래 순서를 바꿉니다. 위에 있는 것이 위에 그려집니다.

```
☑ daegyo_buildings_epsg5186        ← 맨 위
☑ daegyo_site_boundary_epsg5186
☑ daegyo_context_buildings_epsg5186
☑ VWorld 항공영상                   ← 맨 아래
```

### 6-3. 보기 좋게 색 바꾸기 (선택)

1. 레이어 **더블클릭** → **`Symbology`** 탭
2. 위쪽 드롭다운을 **`Categorized`** 로 변경
3. `Value` 를 **`dong`** 으로 선택 → 아래 **`Classify`** 버튼 클릭
4. `OK` → 동별로 색이 나뉩니다

## 7단계. 위치 확인하기

> **위치 보정은 이미 완료되어 있습니다.**
> QGIS에서 실측한 기준점 2점으로 방위각과 위치를 보정한 값이 반영되어 있습니다.
> (도면 상단 방위각 **51.2051°**, 대지 중심 위도 37.522129 / 경도 126.933810)
> 따라서 파일을 불러오면 대체로 제자리에 들어갑니다. 아래에서 눈으로 확인만 하십시오.

확인 방법:

1. 배경지도를 **VWorld 항공영상**으로 켜고
2. `daegyo_site_boundary_epsg5186`(대지경계선)이 **실제 대교아파트 부지**와 맞는지 봅니다
3. 레이어를 반투명하게 하면 보기 편합니다
   - 레이어 더블클릭 → `Symbology` → 아래쪽 **`Opacity`** 를 `50%` 로

**잘 맞으면 9단계(3D 그림자)로 바로 넘어가십시오.**
더 정밀하게 맞추고 싶거나, 나중에 다른 기준점으로 다시 맞추고 싶을 때만 8단계를 보십시오.

### 참고 — 현재 적용된 보정값

| 항목 | 값 |
| --- | --- |
| 도면 상단 방위각 | 51.2051° |
| 대지 중심 | 위도 37.522129 / 경도 126.933810 |
| 사용 기준점 ① | 배치도 픽셀 `262,313` (북서 코너) ↔ EPSG:5186 `194114.76, 547091.16` |
| 사용 기준점 ② | 배치도 픽셀 `1310,313` (북동 코너) ↔ EPSG:5186 `194272.85, 546894.50` |
| 대지경계선 코너 잔차 | 약 4.1 m |

기준점에 **오차 0 m로 완전히 맞춘 버전**은 `outputs\daegyo_cp_exact` 폴더에 따로
들어 있습니다. 다만 이쪽은 대지면적이 인가 제원보다 6.8% 커지므로,
**면적·건폐율·용적률이 중요하면 기본 `outputs\daegyo` 를 쓰십시오.**

## 8단계. 위치 조정하기 (다시 맞추고 싶을 때)

세 가지 방법이 있습니다. **정확도 순서는 방법 C > A > B** 입니다.

### 먼저 할 일 — 실제 좌표 2점 읽기 (모든 방법 공통)

1. 배경지도를 항공영상으로 켜고, 대교아파트 부지를 **최대한 확대**합니다
   (`Scale` 을 `1:1000` 이하로)
2. 부지의 **북서쪽 모서리**(북측 국제금융로7길과 서측 경계가 만나는 지점)에
   마우스 커서를 올립니다
3. 화면 **아래 상태표시줄 `Coordinate`** 에 뜨는 숫자를 적어둡니다
   → 실측값: `194114.76, 547091.16`
4. 같은 방법으로 **북동쪽 모서리**(동측 대로와 만나는 지점) 좌표도 적습니다
   → 실측값: `194272.85, 546894.50`

> **주의 1**: 좌표가 `126.92…, 37.52…` 처럼 소수점 형태로 나오면
> **4단계(좌표계 설정)를 안 한 것**입니다. 다시 하십시오.
> **주의 2**: 여의도의 정상 범위는 **E 194,000~194,400 / N 546,800~547,200** 입니다.
> **주의 3**: 마우스로 짚기 어려우면 `Ctrl` 을 누른 채 휠로 더 확대하십시오.

이 두 점은 배치도 그림에서 각각 **픽셀좌표 `262,313`(북서)** 과
**`1310,313`(북동)** 에 해당합니다. 이 대응관계를 프로그램에 알려주면 됩니다.

### 방법 A. QGIS만으로 평행이동 (파이썬 불필요, 가장 쉬움)

건물이 **회전은 맞는데 통째로 밀려 있을 때** 쓰는 방법입니다.

1. 이동량을 계산합니다
   - 현재 폴리곤의 북서 코너 좌표를 읽습니다
     (대지경계선 레이어에 커서를 올려 `Coordinate` 확인)
   - **이동량 = 실제 좌표 − 현재 좌표**
   - 예: 실제 `194114.76, 547091.16` − 현재 `194117.33, 547088.00` → **ΔX = −2.6, ΔY = +3.2**
2. 메뉴 **`Processing`** → **`Toolbox`** 클릭 (오른쪽에 패널이 열립니다)
3. 패널 위 검색창에 **`Affine`** 입력 → **`Affine transform`** 더블클릭
4. 아래처럼 입력

   | 항목 | 입력값 |
   | --- | --- |
   | Input layer | `daegyo_buildings_epsg5186` |
   | Translation (x-axis) | `40` (계산한 ΔX) |
   | Translation (y-axis) | `40` (계산한 ΔY) |
   | 나머지 | 그대로 둠 |

5. **`Run`** → 새 레이어 `Transformed` 가 생깁니다
6. 위치가 맞는지 확인 후, 레이어 오른쪽 클릭 → **`Export → Save Features As…`** →
   `GeoJSON` 형식으로 저장
7. 같은 이동량으로 `site_boundary`, `context_buildings` 레이어도 반복

> **회전이 필요하면 이 방법을 쓰지 마십시오.** QGIS의 Affine transform은
> 좌표원점(0,0) 기준으로 회전하기 때문에 건물이 수백 km 밖으로 날아갑니다.
> 회전이 필요하면 **방법 B 또는 C**를 쓰십시오.

#### C-7. ★ 위치 보정 실행

7단계에서 읽은 실제 좌표를 넣습니다.

```
python daegyo_site_polygons.py --keep-area-scale --control-points "262,313,194114.76,547091.16;1310,313,194272.85,546894.50"
```

**입력 형식 해설**

```
"262,313,194114.76,547091.16 ; 1310,313,194272.85,546894.50"
 └─┬─┘ └──────┬──────┘   └──┬──┘ └──────┬──────┘
 픽셀좌표   실제 좌표        픽셀좌표    실제 좌표
 (북서 코너)               (북동 코너)
        ← 첫 번째 점 →   ;   ← 두 번째 점 →
```

- 값 사이는 **쉼표**, 두 점 사이는 **세미콜론(;)**
- 전체를 **큰따옴표**로 감쌉니다
- 두 점은 **최대한 멀리** 떨어진 것으로 고르십시오 (가까우면 회전 오차가 커집니다)

**위도·경도로 넣는 경우**

```
python daegyo_site_polygons.py --control-points-crs 4326 --control-points "262,313,126.92730,37.52350;1310,313,126.92990,37.52210"
```

`위도,경도` 순서로 넣어도 자동으로 알아서 바로잡습니다.

| 대지면적 | 26,869.5 ㎡ | 26,869.5 ㎡ | +0.00% |               ← 편차 ±2% 이내면 정상

## 9단계. 3D로 세우고 그림자 보기

### 9-1. 건물에 높이 주기 (3D 돌출)

1. `Layers` 패널에서 **`daegyo_buildings_epsg5186` 더블클릭**
2. 왼쪽 목록에서 **`3D View`** 탭 선택
3. 맨 위 드롭다운을 **`No symbol`** → **`Single symbol`** 로 변경
4. **`Extrusion`** 항목 오른쪽의 작은 버튼
   (데이터 정의 버튼, `E` 모양 또는 자물쇠 옆 아이콘)을 클릭 →
   **`Field type: double`** → **`height_m`** 선택
5. 아래로 스크롤해 **`Altitude clamping`** 을 **`Absolute`** 로,
   **`Altitude binding`** 을 **`Centroid`** 로 설정
6. **`OK`**

`context_buildings` 레이어도 같은 방법으로 설정하십시오. (주변 건물이 있어야
그림자 비교가 됩니다)

### 9-2. 3D 창 열기

1. 메뉴 **`View`** → **`3D Map Views`** → **`New 3D Map View`**
2. 새 창이 열립니다. 조작법:
   - **마우스 휠**: 확대/축소
   - **드래그**: 이동
   - **`Ctrl` + 드래그** 또는 **`Shift` + 드래그**: 시점 회전(기울이기)
3. 건물이 안 보이면 3D 창 위 **`Zoom Full`** 버튼을 누르십시오

### 9-3. 그림자 켜기

1. 3D 창 위쪽 **톱니바퀴 아이콘(`Configure` / `Options`)** 클릭
2. 왼쪽 **`Lights`** 탭 → `Directional Lights` 에서 **`+`** 로 광원 추가
3. 그 광원의 **`Azimuth`(방위각)** 과 **`Altitude`(고도)** 에 아래 표의 값 입력
4. 왼쪽 **`Shadows`** 탭 → **`Show shadows`** 체크
5. **`OK`**

### 9-4. 동지일 태양 위치 (서울 기준)

동지(12월 22일)는 그림자가 1년 중 가장 길어 일조권 검토의 기준일입니다.

| 시각(KST) | Altitude (고도) | Azimuth (방위각) |
| ---: | ---: | ---: |
| 08:00 | `2.1` | `122` |
| 09:00 | `11.6` | `132` |
| 10:00 | `19.6` | `144` |
| 12:30 (남중) | `29.0` | `180` |
| 15:00 | `19.6` | `216` |

**09:00 → 12:30 → 15:00 순서로 값을 바꿔가며** 북측 장미아파트·여의도여고,
서측 삼부아파트 방향에 그림자가 어디까지 지는지 확인하십시오.

> 방위각은 **진북 기준 시계방향**입니다(북=0°, 동=90°, 남=180°, 서=270°).

## 10단계. 일조시간 정량 분석 (선택)

"몇 시간 햇빛이 드는가"를 숫자로 뽑으려면 한 단계가 더 필요합니다.

### 10-1. 폴리곤을 높이 래스터로 변환

1. 메뉴 **`Processing`** → **`Toolbox`**
2. 검색창에 **`Rasterize`** → **`Rasterize (vector to raster)`** 더블클릭
3. 입력

   | 항목 | 입력값 |
   | --- | --- |
   | Input layer | `daegyo_buildings_epsg5186` |
   | Field to use for a burn-in value | **`height_m`** |
   | Output raster size units | `Georeferenced units` |
   | Width/Horizontal resolution | `1` |
   | Height/Vertical resolution | `1` |
   | Output extent | 대상지 전체가 들어가도록 지정 |

4. **`Run`** → 건물 높이 래스터(DSM)가 생성됩니다

### 10-2. UMEP 플러그인으로 그림자 계산

1. 메뉴 **`Plugins`** → **`Manage and Install Plugins…`**
2. 검색창에 **`UMEP`** → **`UMEP for Processing`** 선택 → **`Install Plugin`**
3. `Processing Toolbox` 에서 **`UMEP → Solar Radiation → Shadow Generator`** 실행
4. 10-1에서 만든 래스터를 입력하고 날짜(12월 22일)와 시간 간격을 지정
5. 시간대별 그림자 래스터가 생성되며, 이를 합산하면 **일조시간 지도**가 됩니다

### 10-3. 판단 기준

일조권 분쟁에서 통용되는 수인한도 기준입니다.

- **동지일 09:00~15:00 사이 연속 2시간 이상** 일조 확보, 또는
- **동지일 08:00~16:00 사이 총 4시간 이상** 일조 확보

법정 기준은 「건축법 시행령」 제86조 및 서울특별시 건축조례(공동주택 인동간격,
채광창 방향 이격거리)를 확인하십시오.

## 자주 생기는 문제

| 증상 | 원인과 해결 |
| --- | --- |
| 레이어를 넣었는데 화면에 아무것도 없다 | 레이어 오른쪽 클릭 → **`Zoom to Layer`** |
| 건물이 지도에서 엉뚱한 나라에 있다 | 4단계 좌표계 설정을 안 한 것. `Project → Properties → CRS` → `EPSG:5186` |
| 좌표가 `126.9…` 처럼 소수점으로 나온다 | 같은 원인. 프로젝트 CRS를 5186으로 |
| 건물이 실제 자리와 수십 m 어긋난다 | 정상입니다. **8단계**로 위치 보정 |
| 3D 창에서 건물이 납작한 판으로 보인다 | 9-1의 `Extrusion` 에 `height_m` 필드를 지정하지 않은 것 |
| 3D 창에 `Shadows` 항목이 없다 | QGIS 버전이 낮음(3.16 미만). 최신 LTR로 업그레이드 |
| `python`은 내부 또는 외부 명령이 아닙니다 | 파이썬 설치 시 `Add python.exe to PATH` 를 체크 안 한 것. 재설치 |
| `ModuleNotFoundError: No module named 'shapely'` | `pip install pyproj shapely` 실행 |
| CSV를 엑셀에서 열면 한글이 깨진다 | 이미 UTF-8 BOM으로 저장돼 있습니다. 엑셀에서 `데이터 → 텍스트/CSV 가져오기` 로 열어 인코딩을 `UTF-8` 로 지정 |
| 리포트에 "축척이 …% 차이납니다" 경고 | 기준점 좌표를 잘못 읽음. 8단계 "먼저 할 일"부터 다시 |
