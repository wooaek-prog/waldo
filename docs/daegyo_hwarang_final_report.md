# 대교·화랑아파트 재건축 – 학교 일조권 최종 종합 분석

4개 시나리오에 대해 **학교별 일조시간**과 **아파트별 영향도**를 산출하고,
교사동을 식별할 수 있는 **별도 배치도**를 작성했습니다.

```bash
python3 daegyo_hwarang_final.py --buildings <AL_D010.gpkg> --plan <대교신축.gpkg>
```

| | 시나리오 | 대교아파트 | 화랑아파트 |
| --- | --- | --- | --- |
| **S0** | 재건축 전(현황) | 기존 4개동 12층(35.6m) | 기존 3개동 10층(30m) |
| **S1** | 대교 단독 재건축 | **인가안 4개동 최고 48층(145.6m)** | 기존 3개동 10층 |
| **S2** | 화랑 단독 재건축 | 기존 4개동 12층 | **확정안 1개동 55층(166.3m)** |

### 읽는 법 — 세 가지가 한눈에 보입니다

**① 현황에서 이미 여의도여고만 크게 가려져 있습니다.**
재건축 전에도 대교 1.19h + 화랑 1.35h = 합계 2.67시간을 두 아파트가 가리고
있습니다. 여의도고는 0.00h(전혀 영향 없음), 여의도중은 0.37h에 불과합니다.
여의도여고의 현황 일조가 3.18h로 유독 낮은 이유가 여기 있습니다.

**② 대교 재건축은 모든 학교에 새 그림자를 만듭니다.**
- 여의도고: 0.00h → **0.33h** (현황엔 전혀 영향이 없었는데 새로 생김)
- 여의도중: 0.02h → **0.45h**
- 여의도여고: 1.19h → **1.76h** (+0.57h)

35.6m(12층) → 145.6m(48층)로 4배 높아지면서, 기존엔 그림자가 닿지도 않던
128~138m 거리의 학교까지 새로 도달합니다.

**③ 화랑 재건축은 학교에 따라 정반대로 작용합니다.**
- 여의도여고: 1.35h → **0.96h** (−0.39h, **개선**)
- 여의도중: 0.33h → **0.65h** (+0.32h, 악화)
- 여의도고: 0.00h → **0.16h** (+0.16h, 악화)

바로 옆(13.7m)에 붙어 있던 10층 슬래브 3개가 물러나면서 **여의도여고는
이득**을 보지만, 166m 타워의 긴 그림자가 **북쪽 멀리 있는 여의도중·여의도고
까지 새로 닿아** 그쪽은 손해입니다. 즉 화랑 재건축은 일조 피해를 없앤 게
아니라 **여의도여고에서 여의도중·여의도고로 옮긴 것**입니다.

## 5. 배치도 (별도 도면)

`outputs/daegyo_final/final_site_plan.svg`

- 교사동마다 **①②③ 번호 + 층수 + 4개 시나리오 일조시간**(재건축전 → 대교단독
  → 화랑단독 → 동시)을 표기
- 색상: 빨강 = 1시간 이상 감소, 주황 = 0.3~1시간 감소, 회색 = 변화 없음,
  초록 = 증가
- 대교·화랑 **기존 동은 점선**, **신축은 진한 색**(타워 남색 / 저층부 회색)
- 운동장 근사 영역, 방위표, 축척(50m) 포함

QGIS용 `final_school_units.geojson`에는 동일한 13개 단위가 시나리오별
일조시간·아파트별 영향도 속성과 함께 들어 있습니다.

## 8. 한계

- **운동장은 지적 경계 자료가 없어 "교사동 60m 이내 옥외지반"으로 근사**
  했습니다(여의도여고 25,000㎡ 등 실제 운동장보다 넓음). 절대값보다
  시나리오 간 차이를 보셔야 하며, 실제 경계는 `--playground`로 넣을 수
  있습니다.
- 대교 신축 폴리곤은 배치도 트레이싱(개략)이라 동 위치 ±2~3m 오차가 있습니다.
- 기존 건물 높이는 층수 × 용도별 표준층고 추정값입니다.
- 교사동 창면은 남향계열(방위 90~270°)만, 운동장은 지반 수평면으로
  계산했습니다.
- 40-3은 AL_D010에 건물명이 없어 학교를 특정하지 못했습니다.
- 세부 메커니즘(어느 동이 몇 시에 가리는지)은
  [학교 일조영향 보고서](daegyo_school_sunlight.md)와
  [일조시간 기준 분석](daegyo_school_hours.md)을 참조하십시오.
