# 화랑 A안 상세 폴리곤 — 유엔스튜디오 레퍼런스 적용 (2026-09-26)

확정 방향 **A안**(51층 1개동, 172.3m, 저층부 없음)의 매스를 조감도용 상세
폴리곤으로 만들었다. 설계사 **유엔스튜디오(UNStudio)** 의 레퍼런스 5건(쌍둥이
타워 투시도, Kyklos Building, Palas Residential, EZ Parque da Cidade, Raffles City
Hangzhou)에서 입면 요소를 가져와 타워에 적용했다.

```bash
python3 hwarang_tower_detail.py --buildings <AL_D010.gpkg>   # 폴리곤·GIS·면적표
python3 hwarang_render_A.py                                  # 미리보기 렌더(약 6분)
```

## 일조 분석 결과는 그대로 유지된다

상세 모형은 일조 분석에 쓴 **외형선 각기둥 안쪽**에만 요소를 둔다. 외형선은
62.47 × 15.39m(방위 174°), 높이는 172.3m 다. 그래서 상세 모형의 그림자는 분석
그림자보다 크지 않고, 분석 결과(**건물 신규 불충족 33, 운동장 40, 전체 73**)는
그대로 상한으로 성립한다. 일조를 다시 계산하지 않아도 된다.

스크립트가 실행할 때마다 다음 세 가지를 확인하고, 하나라도 어긋나면 멈춘다.

| 검사 | 결과 |
|---|---|
| 타워 꼭짓점 전부 외형선 안 | 312,120개 중 312,120개 |
| 최고 높이 | 172.30m (분석 172.3m) |
| 연면적 | 37,580.0㎡ = 용적률 **400.00%** (장변 길이를 이분탐색으로 맞춤) |

## 제원

| 항목 | 값 |
|---|---|
| 층수 · 층고 · 높이 | 51층 · 3.3m · 옥탑 크라운 4.0m → **172.3m** |
| 기준층 판 | 59.58 × 12.6m, 모서리 R2.0, **747.1㎡** (분석 판 737㎡ = 59.5 × 12.4m) |
| 연면적 | **37,580㎡** (용적률 400.00%) |
| 층별 면적 | 1층 로비 596 · 2층 747 · A블록 15개층 11,207 · 스카이가든 2개층 1,296 · B블록 16개층 11,954 · C블록 14개층 10,460 · 50층 673 · 51층 646㎡ |
| 발코니 | **3,347㎡** — 서측 픽셀 1.35m 262곳(1,114㎡) + 0.85m 261곳(699㎡), 동측 연속 0.6m 46개층(1,534㎡) |
| 실면적(연면적+발코니) | 40,927㎡ |
| 건축면적(추정) · 건폐율 | 787㎡ · **8.38%** |
| 폴리곤 | 타워 삼각형 104,040개. 대지 조경과 주변 건물 135개를 포함하면 120,600개 |

**실면적은 분석 때보다 줄었다(49,034 → 40,927㎡).** 분석 매스는 판(12.4m)
사방에 1.5m 발코니를 두른 것으로 셈했다(서비스면적 11,454㎡). 이번 모형은 두
가지 이유로 발코니가 적다. 첫째, 픽셀 패턴을 살리려고 발코니를 서측 일부와
동측 0.6m 띠로 줄였다. 둘째, 판을 12.6m 로 넓히고 블록을 엇갈리게 하면서
외형선 안의 여유가 줄었다. 외형선 한도까지 발코니를 채우면(서·동측 1.35m 연속,
단부 0.6m, 46개층) 약 7,400㎡, 실면적 약 45,000㎡ 까지 올릴 수 있다. 이렇게
바꿔도 외형선 안이라 일조 결과는 달라지지 않는다.

**좌표계**: OBJ·GLB 원점은 타워 중심(E194,327.70 N546,974.70, EPSG:5186)이다.
x=동, y=북, z=위, 단위 m. 앞선 `조감_모형.obj` 와 원점이 같아 겹쳐 쓸 수 있다.
GLB 는 glTF 규약에 따라 Y-up 으로 돌려 저장했다. SketchUp, Rhino, Blender,
Lumion, Twinmotion 에서 그대로 열린다.

## 미리보기 렌더

`hwarang_render_A.py` 는 Embree 광선추적으로 그린다. 1차 광선, 그림자, 주변폐색,
유리 반사 1회, 유리 난간 투과를 계산하고, 2×2 초표본과 윤곽선을 더한다.

| 파일 | 시점 |
|---|---|
| `렌더_운동장` | 여의도중 운동장, 눈높이 1.6m, 약 200m (레퍼런스 1 구도, 2점 투시) |
| `렌더_남서조감` | 남서 조감. 서측 픽셀 발코니 입면 |
| `렌더_남동조감` | 남동 조감. 동측 연속 발코니와 핀, 블록 엇갈림 |
| `렌더_북서조감` | 북서 조감. 여의도중·여고 쪽에서 |
| `렌더_서측광장` | 서측 광장 눈높이. 아케이드 로비와 저층 발코니 |
| `렌더_크라운` | 크라운 근경. 50·51층 테라스와 열린 프레임 |
| `렌더_입면` | 서측·북측(단부)·동측 직교 입면. 타워와 대지만 표시 |
| `렌더_배치평면` · `렌더_배치조감` | 위에서 본 배치(직교) · 남쪽 상공 조감 — 어린이집·성큰광장 포함 |
| `렌더_성큰광장` · `렌더_어린이집` | 성큰광장 B1 에서 올려다본 시점 · 놀이마당 건너편 어린이집 |

**햇빛 방향은 시점마다 보기 좋게 고른 연출값이다.** 일조 분석과는 무관하다.
일조 분석은 `hwarang_design_2026.py` 의 동지 08–16시 기준을 따른다.

## 한계

- 실내(코어, 세대 벽)는 모델링하지 않았다. 유리 안쪽 톤은 렌더에서 층·베이마다
  색을 달리해 흉내 냈다.
- 주변은 건물 높이만 반영한 화이트 모델이다. 도로와 지형은 없고 지면은 평면이다.
  학교 운동장은 배치도 해치 경계를 쓴다.
- 수목은 저면 다면체로 단순화했다. 최종 조감도에서는 렌더러의 수목 에셋으로
  바꿔 쓰면 된다.
- 세대 평면과 발코니 확장 여부는 반영하지 않았다. 발코니 면적은 서비스면적
  추정치다.
