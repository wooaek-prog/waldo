# 화랑아파트 재건축 – 저층부 없이 순수 고층안 (2026-09-19)

저층부(포디움·별동)를 **전부 금지**하고 순수 고층 단일·쌍둥이 타워만으로
다시 찾았다. 앞서 낸 최적안(41층+저층부 7층, 신규 불충족 22)과 나란히 두고
쓴다 — 저층부를 두느냐 마느냐의 값을 비교할 수 있게.

```bash
python3 hwarang_design_2026.py --buildings <AL_D010.gpkg> \
    --no-podium --az-step 10 --budget 3600
python3 hwarang_plan_2026.py   --buildings <AL_D010.gpkg> \
    --outdir outputs/hwarang_nopodium_2026
# → outputs/hwarang_nopodium_2026/  report.md · candidates.csv · 배치도
```

## 결론

| | 신규 불충족 | 최고층 | 높이 | 기준층 단변 | 채광이격 |
|---|---:|---:|---:|---:|---|
| 저층부 있음(종전 최적안) | **22** | 41층 | 125.0m | 8.7m | 충족 1.17배 |
| **저층부 없음(이번 최적안)** | **28** | 46층 | 139.7m | **18.4m** | 미충족 0.09배 |
| 저층부 없음 + 채광이격 충족 | 60 | 35층 | 107.2m | 20.7m | 충족 1.01배 |

**저층부를 없애는 값은 신규 불충족 6개(22→28)다.** 그 대신 얻는 건 기준층
단변이 8.7m → **18.4m**로 넓어져 평면이 훨씬 편해진다는 것과(양면복도형
14m 문턱을 넉넉히 넘음), 건물이 한 덩어리라 관리·구조가 단순해진다는 것.
포디움안의 8.7m는 세대깊이 7.2m + 복도 1.3m로 편복도형의 극단(전용
50㎡대 소형 위주)이었는데, 이번 안은 그 문제가 없다.

**단, 채광이격은 포기해야 한다.** 저층부가 없으면 연면적을 전부 타워
하나에 담아야 해서 기준층이 커지고, 커진 기준층은 대지경계에서 멀리
떨어질 자리를 못 찾는다(0.09배 — 규정의 9%). 이격까지 지키려면 35층까지
낮춰야 하는데, 그러면 신규 불충족이 60개로 뛴다. **저층부 없이는
'신규 불충족 최소'와 '채광이격 충족'을 동시에 가질 수 없다** — 포디움안은
둘 다 가졌던 것과 대비된다.

## 최적안 제원 — 46층 단일 타워

| 항목 | 값 |
|---|---|
| 구성 | 46층 · 기준층(연면적선) 817㎡ · **44.5 × 18.4m** · 방위 152° |
| 중심 | E194,262.7 / N546,941.2 · 높이 139.7m |
| 연면적(용적률 산정) | 37,580㎡ · **400.0%** |
| 서비스면적(발코니 1.5m) | 9,087㎡ |
| **실면적(연면적+서비스)** | **46,667㎡** |
| 건축면적 · 건폐율 | 881㎡ · 9.38% |
| 채광이격 여유 | 0.09배 (미충족 — 이격 완화 전제) |
| 신규 불충족 / 신규 충족 | **28** / 34 |

기준층 단변이 18.4m라 8.5/11/14m 세 문턱 모두 같은 안으로 수렴한다 —
저층부가 없으면 연면적을 다 태워야 해서 판이 자연히 두꺼워지고, 그 두께가
이미 양면복도형 기준을 넉넉히 넘는다는 뜻이다(포디움안과 반대 현상).

## 단일 vs 쌍둥이 — 저층부가 없어도 결론은 같다

| 갈래 | 신규 불충족 | 최고층 | 구성 |
|---|---:|---:|---|
| **단일** | **28** | 46층 | 46층 817㎡(44.5×18.4m) |
| 쌍둥이 | 35 | 60층 | 60층 298㎡ + 60층 328㎡(둘 다 13m대) |

저층부 유무와 무관하게 2개동이 1개동보다 나쁘다는 결론은 그대로다(앞
보고서 참조) — 연면적이 고정이면 나누는 순간 폭 대비 면적 효율이 떨어져
그림자 총량이 늘어난다.

## 학교·동별 전후 — 어디가 새로 나빠졌나

| 학교 / 구분 | 신규 불충족 | 저층부안 대비 |
|---|---:|---|
| 여의도여고 본관동 저층부(4층) | **13** | 저층부안은 **0** — 가장 큰 차이 |
| 여의도여고 운동장 | 7 | 저층부안은 0 |
| 여의도중 운동장 | 4 | 저층부안은 8(오히려 이쪽이 적음) |
| 여의도여고 ②(5층) | 2 | 저층부안은 1 |
| 여의도중 체육관동 부속 | 1 | 저층부안은 7(오히려 이쪽이 적음) |
| 여의도고 운동장 | 1 | 저층부안은 0 |
| 나머지 | 0 | — |

**여의도여고 본관동 저층부(4층)가 결정타다.** 16점 중 13점이 새로 불충족
—저층부안에서는 0점이었다. 이 동은 대지에서 가장 가까운 여의도여고(7.1m)
바로 앞에 있어, **저층부(20.7m, 낮고 넓은 매스)보다 46층 순수 타워(139.7m,
높고 좁은 매스)의 그림자가 이 동엔 오히려 더 나쁘다** — 타워가 높아진 만큼
그림자가 길어지는 효과가, 좁아진 만큼 그림자 폭이 줄어드는 효과를 이 특정
동 위치에서는 못 이긴다.

반대로 여의도중 쪽(운동장·체육관동 부속)은 저층부안보다 이번 안이 나은데,
그건 저층부(4,000㎡, 넓게 깔림)가 여의도중 쪽으로도 그림자를 냈기 때문
이다 — 순수 타워는 그 폭이 좁아 여의도중을 덜 스친다.
