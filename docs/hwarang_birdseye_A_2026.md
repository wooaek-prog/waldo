# 화랑 A안 조감도 밑그림 — 주변 건물 포함 (2026-09-23)

확정 방향 **A안(51층 1개동, 저층부 없음)** 으로 조감도 제작용 밑그림을 만들었다.

```bash
python3 hwarang_birdseye_2026.py --buildings <AL_D010.gpkg>
# → outputs/hwarang_birdseye_A_2026/
```

## 장면 구성 (화랑 A안 중심 반경 380m, 120개 건물)

| 구분 | 수 | 높이 출처 |
|---|---:|---|
| **화랑 A안** | 1 | 51층 × 3.3m + 옥탑 4m = **172.3m**, 기준층 59.5×12.4m(외형선은 발코니 1.5m 포함), 방위 174°, 중심 E194,327.7 / N546,974.7 |
| 대교 신축안 | 17 | 인가 배치도 기반 동별 높이(최고 48층) |
| 시범 신축안 | 45 | 일조평가 모델링 배치도 기반 동별 높이 |
| 학교(여의도고·여의도중·여의도여고·여의도초) | 19 | AL_D010 |
| 기존 건물 | 38 | AL_D010 높이·층수 — 이 중 13개는 높이 미상이라 **1층 4m 가정** |

대교·화랑·시범 대지의 **기존** 건물은 신축안으로 대체되므로 넣지 않았다.

## 산출물

| 파일 | 용도 |
|---|---|
| `조감_{남서·남동·남·북동·북서·고각}_주석.png` | 검토용 — 제목·건물 라벨·범례·동지 그림자(12:30, 고각은 10:00) |
| `조감_{…}_원판.png` | **밑그림용** — 글자·그림자 없는 원판. 렌더링·합성 바탕 |
| `*.svg` | 같은 그림의 벡터판(일러스트레이터 등에서 편집 가능) |
| `조감_모형.obj` / `.mtl` | **3D 모형** — SketchUp·Blender·Rhino 로 열어 원하는 시점·재질로 렌더링. 원점 = 화랑 A안 중심(E194,327.70 N546,974.70, EPSG:5186), 단위 m, Z-up, 재질은 구분별 5종 |
| `조감_모형_건물목록.csv` | 모형 속 건물별 구분·높이·바닥면적·출처·중심좌표 |

시점: 카메라가 선 쪽 기준 — 남서(대교 쪽) · 남동 · 정남 · 북동(여의도초 쪽) ·
북서(학교 쪽) · 고각(배치 전경, 앙각 60°). 모두 축측투영(원근 없음)이라
높이·거리 비례가 정확하다. 원근감 있는 조감도는 OBJ 모형을 렌더러에서
찍는 것을 권한다.

## 유의사항

1. 형상은 **매스(각기둥)** 수준이다 — 입면·지붕 형태·저층 상가는 없다.
   대교·시범은 배치도 트레이싱이라 윤곽을 0.8~1.5m 다듬었다.
2. 지형 고저차는 넣지 않았다(여의도는 평지, 모든 건물 지반고 0).
3. 높이 미상 기존 건물 13개(1층 4m 가정)는 CSV 의 `출처` 열에 표시했다.
