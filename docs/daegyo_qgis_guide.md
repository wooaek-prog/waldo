# 여의도 대교아파트 신축안 – QGIS 일조권 분석용 건물 폴리곤 생성 가이드

첨부된 **단지배치도**(축척 1/1000, A1 1/500)와 **사업시행계획인가 제원**을 근거로,
QGIS에서 바로 쓸 수 있는 건물 폴리곤(높이 속성 포함)을 생성하는 절차를 정리한 문서입니다.

## 1. 근거 자료

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 사업명 | 여의도 대교아파트 주택재건축정비사업 (래미안 Y+Z) | 사업시행계획인가 |
| 위치 | 서울특별시 영등포구 여의도동 41 (국제금융로7길 20) | 도로명주소 |
| 대지면적 | 26,869.5 ㎡ | 사업시행계획인가 |
| 건폐율 / 용적률 | 57.02% / 469.99% | 사업시행계획인가 |
| 규모 | 지하 5층 ~ 지상 49층, 4개동, 912세대 | 사업시행계획인가 |
| 동별 층수 | 배치도 표기 기준 101동 48F / 102동 48F·46F / 103동 42F / 104동 43F (저층 연결부 34F) | 첨부 배치도 |
| 계획 지반고 | EL(+)13.3 m | 첨부 배치도 남측 표기 |

> 배치도 표기 최고층수(48F)와 인가 제원 최고층수(49F)가 다릅니다.
> 최종 인가도면을 확보하면 `data/daegyo_site_plan.json`의 `floors` 값을 갱신하십시오.

## 2. 실행 방법

```bash
pip install pyproj shapely
python3 daegyo_site_polygons.py                       # 기본값으로 생성
python3 daegyo_site_polygons.py --outdir outputs/daegyo --epsg 5186
```

주요 옵션

| 옵션 | 설명 |
| --- | --- |
| `--config` | 배치도 트레이싱 정의 JSON (기본 `data/daegyo_site_plan.json`) |
| `--outdir` | 출력 폴더 (기본 `outputs/daegyo`) |
| `--epsg` | 출력 투영좌표계 (기본 5186 = Korea 2000 중부원점, 단위 m) |
| `--plan-up-azimuth` | 배치도 위쪽 방향의 진북 방위각(도). 기본 35° |
| `--anchor-lat`, `--anchor-lon` | 대지 중심 위·경도(WGS84) |
| `--control-points` | 기준점 2점으로 축척·회전·위치 정밀 보정 (권장, 3절 참조) |
| `--no-context` | 주변 기존 건물 참고 레이어 생성 안 함 |

### 좌표 산정 방식

1. **축척**: 대지경계선 폴리곤의 픽셀 면적을 인가 대지면적 26,869.5㎡에 맞추어
   `m/px`를 자동 산정합니다(현재 0.23297 m/px). 배치도의 신설도로 20m,
   국제금융로7길 9m 폭과 교차 검증한 값입니다.
2. **회전·위치**: 기본값은 배치도 방위표 기준 방위각 35°와 개략 앵커 좌표를 사용합니다.
   → **실무 적용 전 반드시 3절의 기준점 보정을 수행하십시오.**

## 3. 위치 정밀 보정 (필수 권장)

기본 앵커 좌표는 개략값이므로, 실제 지적/항공사진 기준으로 보정해야 합니다.

1. QGIS에서 배경지도를 띄웁니다.
   - VWorld 항공영상 또는 국토정보플랫폼 연속지적도 (여의도동 41)
2. 배치도 이미지에서 식별이 쉬운 **2점**(예: 대지경계선 북서측 코너, 북동측 코너)의
   **픽셀좌표**를 읽습니다. (이미지 뷰어 좌상단 원점 기준, `data/daegyo_site_plan.json`의
   `site_boundary_px` 값이 좋은 출발점입니다: 북서 `262,313`, 북동 `1310,313`)
3. QGIS에서 같은 지점의 **EPSG:5186 좌표(E, N)**를 읽습니다.
4. 두 쌍을 넣어 다시 실행하면 축척·회전·위치가 한 번에 맞춰집니다.

```bash
python3 daegyo_site_polygons.py \
  --control-points "262,313,<E1>,<N1>;1310,313,<E2>,<N2>"
```

실행 결과 리포트에 산출된 `도면 축척(m/px)`과 `방위각`이 표시되므로,
축척이 0.233 m/px에서 크게 벗어나면 기준점 입력을 다시 확인하십시오.

## 4. 출력 파일

| 파일 | 내용 |
| --- | --- |
| `daegyo_buildings_epsg5186.geojson` | **신축 건물(타워 12존 + 저층부 5블록)** – 분석 주 레이어 |
| `daegyo_buildings_wgs84.geojson` | 동일 데이터의 WGS84 버전(배경지도 확인용) |
| `daegyo_context_buildings_*.geojson` | 주변 기존 건물(삼부·장미·화랑·한양·여의도여고, 한양 재건축안) 참고 레이어 |
| `daegyo_site_boundary_*.geojson` | 대지경계선 |
| `daegyo_buildings.csv` / `.csvt` / `.prj` | WKT 포함 표 형식 (엑셀·타 프로그램 연계용) |
| `daegyo_trace_preview.svg` | 배치도 이미지와 동일 픽셀좌표계의 트레이싱 검수용 도면 |
| `daegyo_polygon_report.md` | 인가 제원 대비 검증 리포트 |

### 속성 스키마

| 필드 | 설명 |
| --- | --- |
| `id` | 존 식별자 (예: `101-A`) |
| `dong` / `part` | 동 명칭 / 존 구분 |
| `use` | 용도 (공동주택, 근린생활시설 등) |
| `floors` | 지상 층수 |
| `floor_h_m` | 층고 (주거 2.95m, 저층부 4.5m) |
| `roof_m` | 옥탑·파라펫 높이 (주동 4.0m) |
| `height_m` | **건물 높이(G.L. 기준)** = `floors × floor_h_m + roof_m` → 3D 돌출값 |
| `base_elev_m` | 계획 지반고 EL 13.3 m |
| `top_elev_m` | 최고고 (EL 기준) |
| `area_m2`, `gfa_m2` | 건축면적, 층수 환산 연면적 |
| `source` | 데이터 출처/정밀도 표기 |

## 5. QGIS에서 일조·그림자 분석하기

### 5.1 레이어 불러오기

- `Layer → Add Layer → Add Vector Layer`로 `daegyo_buildings_epsg5186.geojson` 추가
- 프로젝트 CRS를 **EPSG:5186**으로 설정 (`Project → Properties → CRS`)
- CSV를 쓸 경우 `Add Delimited Text Layer`에서 `wkt` 필드를 지오메트리로 지정

### 5.2 3D 그림자 (QGIS 내장 3D 맵뷰)

1. 레이어 속성 → `3D View` → `Single symbol`
2. `Extrusion` 을 필드값으로 지정: 식(Expression) 에 `"height_m"`
3. `Altitude clamping = Absolute`, `Altitude binding = Centroid`,
   지반고를 반영하려면 `Altitude` 에 `"base_elev_m"` 입력
4. `View → New 3D Map View` → 톱니바퀴 → `Shadows` 활성화
5. 태양 방위각·고도 입력

동지일(12/22) 서울(위도 37.52°N, 경도 126.93°E) 기준 태양 위치 – 남중시각 약 12:30 KST

| 시각(KST) | 태양 고도 | 태양 방위각(진북 기준) |
| ---: | ---: | ---: |
| 08:00 | 약 2.1° | 약 122° |
| 09:00 | 약 11.6° | 약 132° |
| 10:00 | 약 19.6° | 약 144° |
| 12:30 (남중) | 약 29.0° | 180° |
| 15:00 | 약 19.6° | 약 216° |
| 16:00 | 약 11.6° | 약 228° |

> 위 값은 적위 −23.44°, 균시차 약 +2분을 적용한 개략값입니다. 정밀 검토 시에는
> UMEP의 태양위치 계산이나 `pvlib` 등으로 시각별 값을 산출하십시오.

### 5.3 시간대별 그림자 폴리곤 자동 생성 (권장)

- 플러그인 **UMEP** → `Processing → Solar Radiation → Shadow Generator`
  - 입력: 건물 DSM(래스터). 아래 5.4로 폴리곤을 래스터화해 사용
- 또는 플러그인 **Shadow Analysis / Qgis2threejs**로 시각화

### 5.4 폴리곤 → 건물 DSM 래스터

```
Processing → GDAL → Vector conversion → Rasterize (vector to raster)
  Input      : daegyo_buildings_epsg5186
  Burn field : height_m
  Resolution : 1 m
```

### 5.5 일조권 판단 기준 참고

- 법정 기준: 「건축법 시행령」 제86조(일조 등의 확보를 위한 건축물의 높이 제한) 및
  서울특별시 건축조례 – 공동주택 인동간격, 채광창 방향 이격거리
- 판례상 수인한도(일반적 검토 기준):
  - **동지일 기준 09:00~15:00 사이 연속 2시간 이상 일조** 확보, 또는
  - **동지일 08:00~16:00 사이 총 4시간 이상 일조** 확보
- 검토 대상: 북측 인접 대지(장미아파트·여의도여고·화랑아파트) 및
  서측 삼부아파트, 남측 한양아파트 방향

## 6. 정확도 한계 및 검수 체크리스트

이 데이터는 **래스터 배치도 이미지를 육안 트레이싱**한 결과이므로,
형상 정밀도는 **±2~3m 수준**이며 법적 검토용 성과품이 아닙니다.

- [ ] `daegyo_trace_preview.svg`를 원본 배치도 이미지 위에 100% 크기로 겹쳐 형상 확인
- [ ] `--control-points`로 지적도 기준 위치 보정 완료
- [ ] 최종 인가도면(배치도 CAD/PDF)으로 동별 층수·최고높이 재확인
- [ ] 지반고(EL 13.3m)와 실제 계획고 일치 여부 확인
- [ ] 주변 건물(`context`) 레이어는 개략값 → 실제 분석 시
      국가공간정보포털 **건물통합정보(GIS건물통합정보)** 또는 브이월드 3D 건물데이터로 대체

정밀 성과가 필요하면 조합/설계사(삼성물산·설계사)에서 배치도 **CAD(dwg)** 를 받아
QGIS 또는 CAD에서 직접 변환하는 것이 가장 정확합니다.
