# 화랑 A안 배치도 · 평면도 (2026-09-26)

A안(51층 1개동, 172.3m)의 배치도와 주요 층 평면도다. 배치도에는 대지
남서부 빈 땅에 **어린이집(유치원)** 과 **성큰광장** 을 넣었다. 평면도에는
**코어·엘리베이터 위치**, **PT실** 이 있는 2층 주민공동시설, 여러 세대
타입을 담았다.

```bash
python3 hwarang_plans_A.py --buildings <AL_D010.gpkg> [--check-sun]
python3 hwarang_tower_detail.py --buildings <AL_D010.gpkg>   # 3D 모형에도 반영
python3 hwarang_render_A.py --views 배치평면 배치조감 성큰광장 어린이집
```

대지 프로그램 기하는 `hwarang_site_A.py` 한곳에서 정의한다. 배치도와 3D
모형이 같은 폴리곤을 쓴다.

## 배치도

대지는 76.5 × 122.7m 의 기운 직사각형이다. 타워가 북동부를 대각으로
가로지르고 있어서, 넓게 빈 땅은 남서부다. 이 남서부에 다음을 배치했다.

| 시설 | 규모 | 위치 · 의도 |
|---|---|---|
| **어린이집·유치원** | 지상 2층, 높이 8.0m, 바닥 356㎡ × 2 = 712㎡ | 대지 북서 변 쪽. 산책로 쪽에서 주출입하고 지붕은 정원으로 쓴다. 2층 외벽에 노란 수직 핀을 둔다 |
| **전용 놀이마당** | 533㎡ | 어린이집 남동쪽이라 건물 그림자가 지지 않는다. 울타리를 두르고 가장자리에 그늘목 3그루를 심는다 |
| **성큰광장** | 500㎡, B1 FL −5.0m | 어린이집과 타워 사이. 북동쪽은 계단식 스탠드 10단(단높이 0.5m), 남동쪽은 직통계단, 북서쪽은 B1 카페·작은도서관 유리면 |
| 로비 광장 | 포장 | 타워 서측 아케이드 로비 앞. 성큰광장·산책로와 이어진다 |
| 남서–북동 산책로 | 폭 3m | 대교 쪽에서 여의도초 쪽으로 대지를 관통한다(앞선 요청의 보행로 방향) |
| 지하주차장 램프 | 폭 7m | 동쪽 모서리. 어린이집·놀이마당과 반대편에 두었다 |
| 조경 | 잔디·식재와 수목 | 대지 둘레 가로수와 잔디 가장자리 수림대 |

### 어린이집을 넣어도 일조 결과는 그대로다

2층·8.0m 건물을 대지 남서부 30개 위치에 놓고 학교 수광점 1,074개로
다시 계산했다. 어느 위치든 신규 불충족이 **하나도 늘지 않았다(건물 33 ·
전체 73 그대로)**. 확정 위치로도 같은 결과를 확인했다(`--check-sun`).
낮은 건물의 그림자는 동지 08–16시에 학교 수광점까지 닿지 않는다.

### 면적 개요

| 항목 | 값 |
|---|---|
| 대지 | 9,395㎡ |
| 건축면적 | 1,123㎡ — 타워(기준층 투영) 767 + 어린이집 356 |
| 건폐율 | **11.96%** |
| 연면적(지상) | 38,292㎡ — 타워 37,580 + 어린이집 712 |
| 용적률 산정 연면적 | 36,497㎡ → **용적률 388.5%** |
| 　제외 | 주민공동시설(2층 747㎡, 어린이집 712㎡), 피난안전구역(18·35층 336㎡) |

주민공동시설과 초고층 피난안전구역은 용적률 산정 연면적에서 뺀다(건축법
시행령 119조). 그래서 어린이집을 더해도 400% 안에 들어가고, 약 11% 여유가
남는다. 다만 어린이집이 아니라 **유치원(교육연구시설)** 으로 운영하면 이 공제가
적용되지 않는다. 그래도 2층 주민공동시설과 피난안전구역만 빼면 37,209㎡
(396.1%)이어서 400% 안에 든다.

## 한계 · 확인할 점

- **개략 평면이다.** 실 배치는 비율 틀로 자른 것이다. 구조(기둥·코어벽 두께),
  설비, 세대 내부 문 위치는 실시설계에서 정한다.
- **대지 둘레 도로를 확인하지 않았다.** 수치지도에 도로가 없어 램프와
  어린이집 승하차 위치는 도로를 확인한 뒤 조정해야 한다.
- 2층을 주민공동시설로 쓰는 것은 평면상의 결정이다. 3D 외관(발코니)은
  그대로 두었다.
- 피난안전구역 면적 168㎡ 는 배치상 값이다. 법정 소요 면적(위층 재실자 기준)
  산정은 하지 않았다.
