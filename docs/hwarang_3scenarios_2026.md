# 대교·시범 신축 + 화랑 3안 — 학교 일조 비교 (2026-09-20)

대교·시범은 **두 비교안 모두 신축안**으로 고정하고, 화랑만 세 가지로
바꿔 가며 학교 수광점(기준A: 동지 08~16시, 연속 2h 이상 **또는** 총 4h
이상) 충족·불충족을 비교했다.

```bash
python3 hwarang_daegyo_sibeom_scenarios.py --buildings <AL_D010.gpkg>
```

## 3안

| | 화랑 구성 | 출처 | 최고 높이 |
|---|---|---|---:|
| **A** | 현재상태(기존 10층 3개동) | AL_D010 원본 | 30.0m |
| **B** | 신축(고층) — 41층 282㎡(32.4×8.7m) + 저층부 7층 4,000㎡(84.9×47.1m) | `outputs/hwarang_2026`(2026-09-18 최적안) | 125.0m |
| **C** | 신축(20층 이하) — 20층 1개동 1,879㎡(44.0×42.7m) | `outputs/hwarang_20f_multi_2026`(2026-09-20 최적안) | 70.0m |

**A가 '화랑을 아직 안 건드린' 기준선이므로, B/A·C/A 비교가 화랑
재건축 자체의 순수한 영향이다** — 대교·시범 효과는 세 안에 똑같이
깔려 있어 상쇄된다. B/C 직접 비교는 두 화랑 신축안 중 어느 쪽이
학교에 더 나은지를 answer한다.

B는 그 검토 당시 층고(2.95m), C는 이번 검토에서 지정한 층고(3.3m)를
그대로 쓴다 — 각각 확정된 산출물의 실제 치수이지 이 비교를 위해 새로
다시 계산하지 않았다.

## 확인사항

1. 화랑 고층안(B)·20층이하안(C)은 각각 별도 검토에서 확정된 배치를
   그대로 가져왔다 — 이 스크립트가 새로 최적화하지 않는다. 배치를
   바꾸면(예: C를 앞서 낸 2x2 안이나 보행로형 안으로 바꾸면) 결과가
   달라진다.
2. B·C의 층고가 다르다(2.95m vs 3.3m) — 각 검토의 확정 산출물을 그대로
   쓴 결과이며, 이 비교의 목적(A 대비 순손실 비교)에는 영향이 크지
   않지만 두 안을 같은 층고로 다시 맞추면 차이가 소폭 바뀔 수 있다.
