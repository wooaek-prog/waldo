# 한국 발전소 업체별 급전순위 분석

한국 발전소/발전기 목록을 입력하면 단가를 감안한 급전순위(merit order)를 산출하고, 업체별 누계용량을 함께 확인할 수 있는 간단한 CSV 기반 분석 도구입니다.

## 분석 기준

기본 정렬 우선순위는 다음과 같습니다.

1. `단가` 오름차순: 낮은 단가 발전기를 우선 배치합니다.
2. `회사명` 오름차순: 동일 단가 내에서 업체명을 기준으로 정렬합니다.
3. `발전기명` 오름차순: 동일 업체 내 발전기명을 기준으로 정렬합니다.
4. `용량` 내림차순: 동일 단가/업체/발전기명인 경우 큰 용량을 우선합니다.

출력에는 전체 급전순위, 발전기별 용량, 전체 누계용량, 업체별 누계용량, 단가가 포함됩니다.

## 입력 CSV 형식

필수 컬럼은 아래 4개입니다. 한글 또는 영문 별칭을 사용할 수 있습니다.

| 표준 컬럼 | 허용 별칭 |
| --- | --- |
| 회사명 | `회사명`, `company`, `owner`, `업체명` |
| 발전기명 | `발전기명`, `generator`, `unit`, `plant`, `발전소명` |
| 용량 | `용량`, `capacity`, `mw`, `설비용량` |
| 단가 | `단가`, `price`, `unit_price`, `cost`, `변동비` |

예시는 `data/sample_generators.csv`를 참고하세요.

## 실행 방법

```bash
python3 dispatch_order_analysis.py data/sample_generators.csv --output dispatch_order.csv --company-summary company_summary.csv
```

## 출력 CSV 컬럼

### 급전순위 파일

| 컬럼 | 설명 |
| --- | --- |
| `급전순위` | 단가 기준 전체 급전순위 |
| `회사명` | 발전기 보유/운영 업체명 |
| `발전기명` | 발전기 또는 발전소명 |
| `용량` | 해당 발전기의 용량(MW 등 입력 단위 유지) |
| `누계용량` | 전체 급전순위 기준 누계용량 |
| `업체별누계용량` | 같은 업체 내 급전순위 기준 누계용량 |
| `단가` | 입력 단가 |

### 업체별 요약 파일

| 컬럼 | 설명 |
| --- | --- |
| `회사명` | 업체명 |
| `발전기수` | 업체별 발전기 수 |
| `총용량` | 업체별 총 용량 |
| `최소단가` | 업체 내 최저 단가 |
| `가중평균단가` | 용량 가중 평균 단가 |
| `최대단가` | 업체 내 최고 단가 |

## 주의사항

- 실제 급전은 계통 제약, 정비 상태, 연료 계약, 재생에너지 출력, 송전 제약 등 다양한 운영 조건을 반영할 수 있습니다.
- 이 도구는 입력된 단가와 용량만으로 업체별/발전기별 우선순위를 확인하는 분석용 템플릿입니다.

# 금번(2차) 행정·공공기관 이전 대상 리스트

2026년 9월 3일 정부 '행정·공공기관 이전 및 공공기관 기능 개혁' 발표를 기준으로, 이전 대상으로 거론·발표된 기관을 확정단계와 근거를 붙여 정리한 CSV와 조회 도구입니다.

## 중요: 대상 명단은 아직 확정 전입니다

- 정부는 수도권 소재 공공기관 **350여 곳**을 대상으로 이전 계획을 마련하되, **구체적인 이전 대상 기관과 이전 지역은 2026년 4분기에 확정·고시**할 예정이라고 밝혔습니다.
- 따라서 `data/relocation_targets.csv`는 **확정 명단이 아니라 현재까지 공개된 정보 기준의 후보 리스트**입니다. 각 행에 `확정단계`와 `근거`를 함께 담아 확정 사실과 보도·건의 수준을 구분했습니다.
- 4분기 고시가 나오면 해당 행의 `확정단계`, `이전지역`, `이전시기`, `근거`를 갱신해 사용하세요.

## 확정단계 구분

| 확정단계 | 의미 | 정렬 우선순위 |
| --- | --- | --- |
| `발표확정` | 2026-09-03 발표에서 이전 대상·시기가 명시된 기관 | 1 |
| `발표검토` | 발표에서 이전 방향은 밝혔으나 시기·조건이 유보된 기관 | 2 |
| `언론거론` | 발표문에는 없으나 이전 대상으로 보도된 기관 | 3 |
| `지자체건의` | 지자체가 유치 희망 명단에 담아 정부에 제출한 기관 | 4 |
| `미정` | 확정단계가 확인되지 않은 기관 | 5 |

## 정부 발표 기준 (2026-09-03)

- **중앙행정기관**: 2027년 상반기부터 이전 규모·파급효과가 큰 기관부터 세종으로 순차 이전. 법무부·성평등가족부가 우선 대상으로 제시됐으며, 두 부처는 현행 행복도시법상 이전 제외 기관이어서 법 개정을 함께 추진합니다. 외교부·통일부는 대통령실 세종 이전(2030년), 국회의사당 완공(2033년) 시기와 연계해 검토하고, 별도 청사가 필요한 검찰청·경찰청은 청사 신축 후 이전합니다.
- **공공기관 2차 이전 5대 원칙**: ① 수도권 잔류 최소화 ② 기존 혁신도시 중심 집적 배치 ③ 지역 대학·산업 연계 ④ 자족적 정주기반 확충 ⑤ 속도감 있는 이전(민간 건물 임차 등으로 2027년 선도 이전 착수).
- **공공기관 기능개혁**: 전략적 구조개혁 15개, 유사·중복기능 일원화 11개, 자회사·소규모기관 통폐합 83개 등 총 109개(전체의 약 20%) 감축. 발전 5사 통합(가칭 한국발전), 4개 항만공사 통합, 석유·가스공사 통합, LH 기능 분리 등이 포함됩니다. 통폐합은 이전 대상 기관의 법인격 자체를 바꾸므로 리스트 갱신 시 함께 확인해야 합니다.
- 참고: 1차 이전에서는 혁신도시 10곳을 중심으로 153개 기관, 5만 2000여 명이 이전했습니다.

## 입력 CSV 형식

`기관명`, `기관유형`, `이전지역`, `확정단계`가 필수 컬럼이고 나머지는 선택입니다.

| 표준 컬럼 | 허용 별칭 | 설명 |
| --- | --- | --- |
| 기관명 | `기관명`, `name`, `institution`, `기관` | 이전 대상 기관명 |
| 기관유형 | `기관유형`, `category`, `type`, `구분` | 중앙행정기관/공기업/준정부기관/기타공공기관 등 |
| 소관부처 | `소관부처`, `ministry`, `부처` | 소관 부처 |
| 현소재지 | `현소재지`, `current_location`, `소재지` | 현재 소재지 |
| 이전지역 | `이전지역`, `target_region`, `region` | 확정 또는 거론 중인 이전 지역 |
| 이전시기 | `이전시기`, `schedule`, `timeline` | 이전 예정 시기 |
| 확정단계 | `확정단계`, `stage`, `status` | 위 확정단계 구분 값 |
| 근거 | `근거`, `source`, `출처` | 발표일 또는 보도 시점 |
| 비고 | `비고`, `note`, `remark` | 쟁점·제약 사항 |

## 실행 방법

```bash
# 전체 리스트 조회 (기본 입력: data/relocation_targets.csv)
python3 relocation_target_list.py

# 확정된 기관만 CSV로 저장
python3 relocation_target_list.py --stage 발표확정 --stage 발표검토 --output confirmed.csv

# 부산 거론 기관만 조회
python3 relocation_target_list.py --region 부산

# 기관명·소관부처·비고 검색 및 집계 저장
python3 relocation_target_list.py --keyword 금융위원회 --summary relocation_summary.csv
```
