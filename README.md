# 한국 발전소 업체별 급전순위 분석

한국 발전소/발전기 목록을 입력하면 단가를 감안한 급전순위(merit order)를 산출하고, 업체별 누계용량을 함께 확인할 수 있는 간단한 CSV 기반 분석 도구입니다.

## 분석 기준

기본 정렬 우선순위는 다음과 같습니다.

1. `단가` 오름차순: 낮은 단가 발전기를 우선 배치합니다.
2. `회사명` 오름차순: 동일 단가 내에서 업체명을 기준으로 정렬합니다.
3. `발전기명` 오름차순: 동일 업체 내 발전기명을 기준으로 정렬합니다.
4. `용량` 내림차순: 동일 단가/업체/발전기명인 경우 큰 용량을 우선합니다.

출력에는 전체 급전순위, 발전기별 용량, 전체 누계용량, 업체별 누계용량, 단가가 포함됩니다.

## 입력 CSV 형식

필수 컬럼은 아래 4개입니다. 한글 또는 영문 별칭을 사용할 수 있습니다.

| 표준 컬럼 | 허용 별칭 |
| --- | --- |
| 회사명 | `회사명`, `company`, `owner`, `업체명` |
| 발전기명 | `발전기명`, `generator`, `unit`, `plant`, `발전소명` |
| 용량 | `용량`, `capacity`, `mw`, `설비용량` |
| 단가 | `단가`, `price`, `unit_price`, `cost`, `변동비` |

예시는 `data/sample_generators.csv`를 참고하세요.

## 실행 방법

```bash
python3 dispatch_order_analysis.py data/sample_generators.csv --output dispatch_order.csv --company-summary company_summary.csv
```

## 출력 CSV 컬럼

### 급전순위 파일

| 컬럼 | 설명 |
| --- | --- |
| `급전순위` | 단가 기준 전체 급전순위 |
| `회사명` | 발전기 보유/운영 업체명 |
| `발전기명` | 발전기 또는 발전소명 |
| `용량` | 해당 발전기의 용량(MW 등 입력 단위 유지) |
| `누계용량` | 전체 급전순위 기준 누계용량 |
| `업체별누계용량` | 같은 업체 내 급전순위 기준 누계용량 |
| `단가` | 입력 단가 |

### 업체별 요약 파일

| 컬럼 | 설명 |
| --- | --- |
| `회사명` | 업체명 |
| `발전기수` | 업체별 발전기 수 |
| `총용량` | 업체별 총 용량 |
| `최소단가` | 업체 내 최저 단가 |
| `가중평균단가` | 용량 가중 평균 단가 |
| `최대단가` | 업체 내 최고 단가 |

## 주의사항

- 실제 급전은 계통 제약, 정비 상태, 연료 계약, 재생에너지 출력, 송전 제약 등 다양한 운영 조건을 반영할 수 있습니다.
- 이 도구는 입력된 단가와 용량만으로 업체별/발전기별 우선순위를 확인하는 분석용 템플릿입니다.

# 여의도 화랑아파트 재건축 – 학교 일조영향 최소화 배치안

GIS건물통합정보(AL_D010)와 대교아파트 신축 폴리곤을 조합하여, 준주거 용적률 400% /

# 여의도 화랑아파트 재건축 – 설계안 재도출 (보정 데이터 기준)

보정된 학교 건물 집합(교사동 12개동 + 운동장 4개소)과 대교 재건축안이 지어진
상태를 전제로, 준주거 400%/60% 안에서 학교 일조피해가 가장 작은 설계안을
처음부터 다시 도출했습니다.

```bash
python3 hwarang_redesign.py --buildings <AL_D010.gpkg> --daegyo <대교신축.gpkg>
```

**핵심**: 용적률 400%가 고정이라 층수를 올리면 기준층이 작아져 **그림자 폭이
좁아집니다.** 그래서 우선순위 ①일조·②고층화·④조망이 서로 충돌하지 않고
같은 방향으로 움직이며, 일조는 **75층에서 포화**됩니다. 1개동이 2개동보다
우월하고, 용적률을 300%로 낮춰도 일조는 동일해 **400% 유지가 맞습니다.**

다만 **세대 배치**(단변 ≥ 18.17m)와 **채광 이격**(건축법 시행령 §86③1,
준주거 4배)이 고층안을 잘라내, 답이 두 트랙으로 갈립니다.

발코니(서비스면적 1.5m)를 반영해 전면 재계산한 최종 결론입니다. 그림자는
**외형선(발코니 끝)** 이 만들고, 건폐율은 건축면적선(발코니 끝 −1m) 기준입니다.

| | 트랙 A(이격 완화 전제) | 트랙 B(현행 규정 충족) |
| --- | --- | --- |
| 구성 | 1개동 **75층** 1.5:1 (연면적선 27.4×18.3m) | 1개동 **35층** 1.75:1 (43.3×24.8m) |
| 외형선(그림자) | 647㎡ (30.4×21.3m) | 1,287㎡ (46.4×27.8m) |
| 교사동 기준A | **80.9%** (기존 78.6% 대비 **+2.3%p**) | **77.9%** (**−0.8%p**) |
| 한강 조망 | 90.8% | 80.8% |

**현행 채광 이격 규정(준주거 4배)을 지키면서 용적률 400%를 채우면, 어떤
층수·형상으로도 학교 일조가 기존보다 나아지지 않습니다**(트랙 B 정점 35층
−0.8%p). 개선하려면 이격 완화가 전제되어야 하고 그 경우 +2.3%p까지 가능합니다.
조감도 4시점 포함 → [docs/hwarang_redesign_report.md](docs/hwarang_redesign_report.md)

# 학교별 수광점(受光點) 정의 – 도면 기반 재정의

일조 분석의 정확도는 그림자 계산보다 **"어디를 교실 창으로 보느냐"** 에 더 크게
좌우됩니다. 학교별 도면을 받는 대로 종전 일반식(외벽 5m 균등 · 남향계열 외벽
전체 · 층고 3.5m · 창중심 1.2m)을 실제 창면으로 교체하고 있습니다.

```bash
python3 school_footprint_key.py    --buildings <AL_D010.gpkg> --jibun 40-2  # 동 식별도
python3 school_receptor_drawing.py --buildings <AL_D010.gpkg> --jibun 40-2
```

수평 배치는 **교육환경평가 분석지점도와 같은 방식**입니다 — 교실 모듈(기본 9.0m)에
교실당 창 2개소(교실 중심 ±1.8m), 계단실·출입구·필로티 제외. 여의도여고 지침서를
이 규칙으로 재현하면 층별 점 수가 **도면과 정확히 일치**합니다 — 본관동 66점
(5층 10 / 4층 16 / 3층 16 / 2층 14 / 1층 10), A동 33점(1·2층 각 12 / 3층 9).
동에 따라 창 배치가 달라 모듈은 동·면·층별로 둘 수 있습니다(A동은 단창 4.5m,
3층 리본창은 면별 7.7m / 5.8m).

| 학교 | 상태 | 수광점 |
| --- | --- | --- |
| 여의도초등학교 (40-3) | 본관·별관 정면도 반영 | **134** |
| 여의도중학교 (40-1) | 체육관동 4면도 + 본관 정면도 반영 | **289** |
| 여의도여자고등학교 (40-2) | 본관동·A동 지침서 반영 | **99** |
| 여의도고등학교 (30-1) | 본관동 정면도 확보, 평면 대조 필요 | – |

층고도 도면 실측으로 바뀌었습니다 — 여의도중 본관은 1층만 3.9m·2층 이상 3.6m,
여의도여고 본관동은 3.7m로, 종전 3.5m 균일 가정과 다릅니다.

⚠️ 이 과정에서 AL_D010 에 **용도·층수·높이가 모두 비어 있어 종전 분석에서 통째로
빠져 있던 787.5㎡ 건물**(여의도중 체육관동 부속)을 4면도로 복원했습니다.
수광점은 넣었으나 **그림자를 만드는 건물로는 아직 반영되지 않았습니다** —
일조 재계산 시 함께 넣어야 합니다.

# 수광점별 학교 일조권 충족여부 – 화랑 재건축 전후

도면 기반 수광점(위 절)에 **운동장 지반**을 더해, 수광점 하나하나의 충족여부를
내고 화랑 재건축 전후를 비교합니다. 두 시나리오 모두 **대교는 신축안이 지어진
상태**로 고정해, 차이가 **화랑 재건축만의 순수 영향**이 되게 했습니다.

```bash
python3 school_receptor_compliance.py --buildings <AL_D010.gpkg>
# → outputs/school_compliance/  step1~3 CSV + qgis/ 레이어
#   docs/school_receptor_compliance.md
```

수광점 **1,823개** = 교사동 창면 863(도면기준 522 / 일반식 341) + 운동장 지반 960
(8m 격자). 운동장은 실제 경계가 아니라 근사입니다 — 교사동에서 60m 이내의
옥외지반 중 **그 학교가 다른 어떤 건물보다 가까운** 격자점만 남겨 가장 가까운
학교에 배정해, 학교끼리 겹치지 않게 했습니다(`--playground` 로 실제 폴리곤 대체 가능).

| 학교 | 수광점 | S1 충족률(화랑 기존) | S2 충족률(화랑 신축) | 변화 | 신규 불충족 | 신규 충족 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 여의도고등학교 | 629 | 86.2% | 85.2% | −1.0%p | 6 | 0 |
| 여의도중학교 | 497 | 80.7% | **72.0%** | **−8.7%p** | 45 | 2 |
| 여의도여자고등학교 | 335 | 55.8% | 64.8% | **+9.0%p** | 17 | 47 |
| 여의도초등학교 | 362 | 88.7% | 90.1% | +1.4%p | 1 | 6 |
| **전체** | **1,823** | **79.6%** | **78.8%** | **−0.8%p** | **69** | **55** |

피해가 **여의도중학교에 집중**됩니다. 특히 이번에 복원한 **체육관동 부속(원형부)**
48개 수광점은 43.8% → **0%** 로 전멸합니다. 반대로 여의도여고는 운동장(41.1% →
59.6%)과 A동(51.5% → 84.8%)이 크게 좋아집니다 — 기존 화랑 5개동이 한 동으로
모이며 그림자가 비켜갑니다.

충족률만 보면 −0.8%p지만 **평균 총일조는 4.33h → 4.08h(−0.25h)** 로, 문턱을
넘은 채 시간을 잃는 수광점이 훨씬 많습니다.

**수광점 자료 근거 등급**: 1,823개가 모두 같은 근거가 아닙니다 —
**1,301개(71%)는 도면 없이 추정**한 것입니다(일반식 341 + 운동장 근사 960).

# 화랑 설계안 재도출 – '신규 불충족 0' 목표

목표를 바꿔 다시 도출했습니다. 종전에는 학교 일조 **충족률을 최대화**했는데,
이번에는 **현재(대교 신축안 + 화랑 기존)에서 충족하던 수광점이 하나도 불충족으로
떨어지지 않는** 안을 찾습니다(원래 불충족이던 점은 그대로 둠).

```bash
python3 hwarang_zero_newfail.py --buildings <AL_D010.gpkg>   # 탐색(A~D)
python3 hwarang_zero_push.py    --buildings <AL_D010.gpkg>   # 경계 확장(E)
python3 hwarang_zero_final.py   --buildings <AL_D010.gpkg>   # 정밀·용적률(F/G)
python3 hwarang_zero_report.py  --buildings <AL_D010.gpkg>   # 확정안 보고서
```

**결론: 신규 불충족 0 은 달성하지 못했습니다. 최선이 23개입니다.**

| 단계 | 최적안 | 신규 불충족 |
| --- | --- | ---: |
| 참고 – 화랑 철거·미신축 | (하한) | 0 |
| 참고 – 현행 트랙B 35층 | | 69 |
| A 단순 타워 | 55층·2:1·165° | 59 |
| B 층수·세장비 | 51층·4:1·165° | 55 |
| C 저층부 확대 | 39층 + 저층부 2,800㎡ | 32 |
| D 미세조정 | 39층·3.125:1 | 27 |
| **F 정밀 미세조정** | **42층·3.9:1·166.5° + 저층부 2,800㎡** | **23** |

## 확정안

**42층 · 3.9:1 · 방위 166.5° · 기준층 299㎡(34.2×8.8m) + 저층부 1~10층
2,800㎡(66.9×41.8m, 대지 장축 52° 정렬)**
높이 127.9m · 연면적 37,581㎡(용적률 400.0%) · 건축면적 2,910㎡(건폐율 30.97%) ·
서비스면적 7,764㎡

전체로는 **개선**입니다 — 충족 1,451 → 1,472개(+1.2%p), 신규 충족 44 >
신규 불충족 23, 평균 일조 −0.12h(현행 트랙B는 −0.25h).
여의도고 629점과 여의도중 본관 153점은 **신규 불충족 0**, 여의도여고 A동은
14점이 신규 충족(51.5% → 93.9%)입니다.

## 왜 0이 안 되는가

용적률 400%는 9,395㎡ 대지에 37,580㎡를 담으라는 뜻입니다. 39층이면 119m이고
동지 정오 그림자가 **215m** — 북쪽 60~380m의 학교를 반드시 쓸고 지나갑니다.
저층부로 연면적을 옮겨 타워를 8.8m까지 가늘게 만드는 것이 최선이며, 그래도
통과 시간을 2시간 아래로 못 줄이는 지점이 남습니다. 층수를 39층 아래로 내려도
마찬가지였습니다(25층 23개 · 20층 29개, 요구조건 범위 밖 참고 스윕).

남은 23개는 **전부 '연속 2시간'에서 탈락**하고 여의도중 운동장·체육관동과
여의도여고 운동장에 몰려 있습니다.

⚠️ 이 안은 대지경계 최소이격 8.2m로 **채광이격(높이 1/2 = 64.0m)에 미달**합니다.
종전 분류로는 트랙 A형(이격 완화 전제)입니다.
