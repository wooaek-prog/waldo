# 재건축 인접 학교 일조권(일영) 계산기

재건축·재개발 등으로 들어서는 신축 매싱이 인접한 학교 교실 창문의 일조에
미치는 영향을, 개략적인 3D 매싱(박스형 압출 다각형)을 기반으로 특정 날짜
기준 시뮬레이션하는 도구입니다.

## 대상 사례

- **필지**: 서울특별시 영등포구 여의도동 40-4 (여의도 화랑아파트 소규모재건축사업)
- **인접 학교(창문 기준 검토 대상)**: 서울여의도초등학교, 여의도중학교(구 여의도여자중학교), 여의도여자고등학교
- 예시 설정 파일: [`data/site_yeouido_40_4.json`](../data/site_yeouido_40_4.json)

## 계산 방법

1. **태양 위치 계산** (`sunlight/sun_position.py`): NOAA Solar Calculator 공개
   계산식을 그대로 구현해, 위도·경도·일시로부터 태양 고도(elevation)와
   방위각(azimuth)을 구합니다.
2. **개략 3D 매싱** (`sunlight/geometry.py`): 신축 건물과 학교 건물을 각각
   `평면 다각형(footprint) + 바닥표고 + 높이`로 압출한 수직 프리즘으로
   단순화합니다. 발코니, 처마, 옥탑, 경사지붕 등 세부 형상은 반영하지
   않습니다.
3. **창문(교실) 표본점**: 학교 건물의 파사드(벽면)마다 층수 × 층당 창문
   개수만큼 표본점을 균등 배치합니다(`sunlight/model.py`). 각 표본점은
   해당 벽면이 바라보는 바깥쪽 방향의 법선 벡터를 가집니다.
4. **차폐 판정**: 각 시각마다 표본점에서 태양 방향으로 레이를 쏘아, (a) 창이
   태양 반대쪽을 보고 있지 않은지(자기 건물 자기차폐 포함), (b) 신축
   매싱·다른 학교동 등 다른 프리즘에 가로막히지 않는지를 판정합니다
   (`sunlight/analysis.py`).
5. **집계 및 기준 판정**: 하루 중 08:00~16:00 구간을 지정 간격(기본 10분)
   으로 샘플링하여
   - **총일조시간**: 08:00~16:00 사이 일조로 판정된 샘플 시간의 합
   - **연속일조시간**: 09:00~15:00 사이 일조가 끊기지 않고 이어진 최대 시간

   을 계산하고, **연속 2시간 이상 또는 총 4시간 이상**이면 해당 창문은
   기준을 충족하는 것으로 판정합니다.

## 판정 기준의 출처와 한계

"동지일 기준 09~15시 연속 2시간 이상, 또는 08~16시 총 4시간 이상"은
공동주택 일조 확보와 관련해 각 지자체 건축조례 등에서 널리 쓰이는 수치를
학교 교실 일조 검토에 **참고 기준으로 준용**한 것입니다. 학교(교육시설)에
대해 이 수치를 그대로 강제하는 단일 법령은 없으며, 실제 인허가·환경영향
(교육환경) 평가에서는 관할 교육청·지자체가 적용하는 기준과 개별 사례별
검토 결과를 따라야 합니다. 본 도구는 정량적 스크리닝/시나리오 비교
용도로만 사용하십시오.

## 입력 데이터(JSON) 형식

```jsonc
{
  "site": {
    "name": "...", "parcel": "...", "address": "...",
    "latitude": 37.52, "longitude": 126.93, "timezone": "Asia/Seoul"
  },
  "obstructions": [
    { "id": "고유ID", "name": "신축동 이름",
      "footprint": [[x1,y1], [x2,y2], ...],  // 로컬 ENU, 단위 m, 시계/반시계 무관
      "base_z": 0.0, "height": 175.0 }
  ],
  "schools": [
    { "id": "학교ID", "name": "학교명",
      "buildings": [
        { "id": "동ID", "name": "동 이름",
          "footprint": [[x,y], ...], "base_z": 0.0, "height": 18.0,
          "facades": [
            { "name": "입면 이름", "wall": [[x1,y1],[x2,y2]], "normal": [nx, ny],
              "floor_height": 3.6, "num_floors": 5, "windows_per_floor": 8,
              "sill_height": 1.0 }
          ]
        }
      ]
    }
  ]
}
```

좌표계는 위경도가 아니라 **로컬 ENU(동=+X, 북=+Y, 상=+Z, 단위 m)** 평면
좌표입니다. 부지 규모(수백 m 이내)에서는 위경도 대신 평면 근사를 써도
오차가 무시할 만한 수준이며 기하 계산이 훨씬 단순해집니다. `site`의
`latitude`/`longitude`만 실제 위경도를 사용해 태양 위치를 계산합니다.

`schools[].buildings[]`에 등록된 건물은 자동으로 차폐 매싱(obstructions)
목록에도 추가되므로, 학교 자체 동끼리 서로 그림자를 드리우는 경우도 함께
반영됩니다(창문을 소유한 동 자신은 차폐 판정에서 제외).

## 실행 방법

```bash
python3 sunlight_analysis.py data/site_yeouido_40_4.json \
    --date 2026-12-22 \
    --interval 10 \
    --output window_report.csv \
    --summary school_summary.csv \
    --timeline timeline.csv   # 선택: 시간대별 상세 로그
```

- `--date`를 생략하면 가장 가까운 동지(12월 22일 근사)를 기본값으로
  사용합니다. 동지는 태양 고도가 연중 가장 낮아 그림자가 가장 길어지는
  '최악 조건일'이므로 일조권 검토에 관행적으로 쓰입니다.
- `--interval`은 시간 샘플 간격(분)입니다. 값이 작을수록 정확하지만
  계산 시간이 늘어납니다.

### 출력

- **`window_report.csv`**: 창문(표본점) 단위 총일조/연속일조 시간과
  기준 충족 여부
- **`school_summary.csv`**: 학교/동/입면/층 단위로 묶어 최소값(최악
  케이스) 기준 적합·부적합 요약
- **`timeline.csv`** (선택): 창문별 시각별 태양 고도·방위·일조 여부 로그

## 예시 결과 (여의도동 40-4, 2026-12-22 동지 기준)

`data/site_yeouido_40_4.json`으로 실행하면, 신축동과 가장 정면으로
마주보고 거리도 가장 가까운 **서울여의도초등학교** 남측 저층 창문
일부가 연속·총량 기준 모두 미달로 나타나며, 신축동 폭 바깥쪽으로 비켜난
**여의도중학교·여의도여자고등학교** 창문은 기준을 충족합니다. 이는 실제
언론 보도에서 제기된 "재건축이 인접 학교 일조권을 침해할 수 있다"는
우려와 정성적으로 부합하는 결과이며, 신축동의 위치·폭을 조정했을 때
영향이 어떻게 달라지는지 비교하는 용도로 활용할 수 있습니다.

**주의**: 이 예시의 부지 좌표·건물 형상·이격거리·층고는 언론보도 수치
(부지면적 9,395㎡, 지상 49층 1개동 285세대)를 참고해 만든 근사치입니다.
실제 검토에는 조합 설계도서, 국토교통부 브이월드 3D 건물 데이터, 학교
시설 도면으로 좌표와 치수를 반드시 실측값으로 교체해야 합니다.

## 한계

- 건물을 수직 프리즘으로 단순화하므로 발코니, 차양, 경사지붕, 옥탑 등은
  반영되지 않습니다.
- 인접 건물의 반사광(간접광)은 고려하지 않고 직사광만 판정합니다.
- 대기굴절 보정을 적용하지 않습니다(그림자 판정에는 영향이 미미).
- 하루 단위 스냅샷 시뮬레이션이며, 계절별(하지·춘추분 등) 비교가
  필요하면 `--date`를 바꿔 여러 번 실행해 비교하십시오.
