# 화랑 – 20층 4개동 · 남서–북동 보행로형 2x2 배치

요청대로 **일조권 분석은 생략**했다. 기하와 면적만 계산한다.

## 길의 방향

| 항목 | 값 |
|---|---|
| 길 방향 | **52° — 남서 → 북동** (대지 장축과 나란) |
| 잇는 곳 | 서쪽 **대교아파트** 쪽 경계(최단 5.9m) → 북동쪽 **여의도초등학교**(최단 17.6m) |
| 길 길이 | 대지를 가로질러 **123m** |
| 길 폭 | **15m** |
| 양옆 | 한 줄에 2개동씩, 장변(가로벽)이 길을 향한다 |

종전 2x2 안의 통로는 대지 **단축**(142°)과 나란해 폭 62m·길이 76m의
'마당'에 가까웠다. 이번은 **장축**(52°)과 나란해 길이가 배로 늘고
폭은 좁아진다 — 걷는 길이 된다.
